# Snowflake - Gold Layer Generation Prompt

**Purpose:** Generate production-ready Snowpark Python code for Gold layer (business-ready analytics views)

## 🤖 Agent Instructions

You are an expert Snowflake Data Engineer. Generate Gold layer code using Snowpark that creates business-ready views for analytics and BI tools.

### What is the Gold Layer?
The Gold layer is the **business presentation zone** with:
- **Aggregations** for KPIs and dashboards
- **Business calculations** and derived metrics
- **Denormalized views** for query performance
- **Dimensional models** (Facts and Dimensions)

### Your Mission:
Generate Snowpark code that:

1. **Reads from Silver layer**
2. **Applies business logic** (calculations, aggregations)
3. **Creates optimized views** for analysts
4. **Handles DIMENSION vs FACT tables**
5. **Uses overwrite mode** (Gold is rebuilt)
6. **Logs execution**

## 📐 Mandatory Code Structure

```python
# ==============================================================================
# GOLD LAYER - BUSINESS VIEW (SNOWFLAKE)
# ==============================================================================
# Generated by: Legacy2Lake UTM Platform - Agent C (Interpreter)
# Source: {source_table}
# Target: {schema_gold}.{table_name}
# Table Type: {DIMENSION|FACT}
# Generated: {timestamp}
# ==============================================================================

import snowflake.snowpark as snowpark
from snowflake.snowpark import Session
import snowflake.snowpark.functions as F
import logging

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

def main(session: Session) -> str:
    """
    Gold layer business view creation.
    
    Args:
        session: Snowpark Session
    
    Returns:
        str: Status message
    """
    
    # CONFIGURATION
    SCHEMA_SILVER = "SILVER_CURATED"
    SCHEMA_GOLD = "GOLD_BUSINESS"
    SOURCE_TABLE = "{source_table}".upper()
    TARGET_TABLE = "{target_table}".upper()
    TABLE_TYPE = "{DIMENSION|FACT}"
    
    try:
        logger.info(f"Starting Gold layer for {TARGET_TABLE}")
        
        # READ SILVER
        silver_table = f"{SCHEMA_SILVER}.{SOURCE_TABLE}"
        df_silver = session.table(silver_table)
        
        logger.info(f"Read {df_silver.count()} records from Silver")
        
        # APPLY BUSINESS LOGIC
        if TABLE_TYPE == "DIMENSION":
            # Dimension: Business-friendly projections
            df_gold = df_silver.select(
                F.col("CUSTOMER_ID").alias("CUSTOMER_KEY"),
                F.col("CUSTOMER_NAME"),
                F.col("EMAIL"),
                F.col("COUNTRY"),
                # Business labels
                F.when(F.col("STATUS") == "A", F.lit("Active")) \
                 .otherwise(F.lit("Inactive")).alias("STATUS_LABEL"),
                # Audit
                F.col("_INGESTION_TIMESTAMP").alias("LAST_UPDATED")
            )
        
        elif TABLE_TYPE == "FACT":
            # Fact: Computed measures
            df_gold = df_silver.select(
                F.col("ORDER_ID").alias("ORDER_KEY"),
                F.col("CUSTOMER_ID").alias("CUSTOMER_KEY"),
                F.col("PRODUCT_ID").alias("PRODUCT_KEY"),
                F.col("ORDER_DATE").alias("DATE_KEY"),
                F.col("QUANTITY"),
                F.col("UNIT_PRICE"),
                # Computed measures
                (F.col("QUANTITY") * F.col("UNIT_PRICE")).alias("TOTAL_AMOUNT"),
                ((F.col("QUANTITY") * F.col("UNIT_PRICE")) * F.col("DISCOUNT_PCT")).alias("DISCOUNT_AMOUNT"),
                # Audit
                F.current_timestamp().alias("PROCESSED_TIMESTAMP")
            )
        
        else:
            # Default: Passthrough
            df_gold = df_silver.select("*")
        
        logger.info(f"Applied {TABLE_TYPE} business logic")
        
        # VALIDATE
        record_count = df_gold.count()
        if record_count == 0:
            raise ValueError(f"No records for Gold layer: {TARGET_TABLE}")
        
        logger.info(f"Validated: {record_count} records")
        
        # WRITE TO GOLD
        target_gold_table = f"{SCHEMA_GOLD}.{TARGET_TABLE}"
        
        df_gold.write \
            .mode("overwrite") \
            .save_as_table(target_gold_table)
        
        success_msg = f"✅ Gold layer updated: {target_gold_table} ({record_count} records)"
        logger.info(success_msg)
        
        return success_msg
    
    except Exception as e:
        error_msg = f"❌ Gold layer failed: {str(e)}"
        logger.error(error_msg)
        raise Exception(error_msg)
    
    finally:
        logger.info("Gold layer process completed")


if __name__ == "__main__":
    session = snowpark.Session.builder.getOrCreate()
    result = main(session)
    print(result)
```

- Add flags/labels: `WHEN...THEN`
- Handle NULLs: `F.coalesce()`

### ✅ Write Strategy:
- **Mode:** `overwrite` (rebuild daily)
- **Format:** Native Snowflake table

## ❌ Common Mistakes

### 1. Using Append Mode
```python
# ❌ WRONG
.mode("append")

# ✅ CORRECT
.mode("overwrite")
```

### 2. Technical Column Names
```python
# ❌ WRONG
F.col("cust_id"), F.col("prod_cat_cd")

# ✅ CORRECT
F.col("cust_id").alias("CUSTOMER_KEY"),
F.col("prod_cat_cd").alias("PRODUCT_CATEGORY")
```
