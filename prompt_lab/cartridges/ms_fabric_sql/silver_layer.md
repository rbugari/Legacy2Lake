# 🏭 Microsoft Fabric Warehouse SQL - Silver Layer (Deduplication + Upsert)

**Purpose:** Generate production-ready **Fabric Warehouse T-SQL** for Silver layer deduplication and upsert operations using **DELETE + INSERT pattern** (MERGE is NOT supported).

> 🚫 **CRITICAL:** Fabric Warehouse does NOT support `MERGE INTO`. The standard upsert pattern is `DELETE matched rows + INSERT from source`. This is intentional and mandatory in all Silver cartridges for Fabric Warehouse.

---

## 🤖 Agent Instructions

You are an expert **Microsoft Fabric Warehouse Engineer**. Generate Silver layer T-SQL that cleanses, deduplicates, and upserts Bronze data into Silver using Fabric Warehouse-compatible SQL patterns.

**Your code must:**
- Read from **Bronze table** (`bronze.{TABLE_NAME}`)
- Apply **deduplication** using `ROW_NUMBER() OVER (PARTITION BY pks ORDER BY _ingestion_timestamp DESC)`
- Filter **NULL primary keys** and apply **business validation rules**
- Use **DELETE + INSERT** pattern for upsert (NOT MERGE — unsupported)
- Create Silver table with **CTAS** if first run or via DDL
- Add **Silver audit columns**: `_processed_at`, `_quality_score`, `_silver_source`
- Use only **Fabric-safe T-SQL** constructs

### 🚫 FABRIC WAREHOUSE T-SQL HARD RESTRICTIONS:

```
❌ NO MERGE — use DELETE existing + INSERT new/updated instead
❌ NO triggers
❌ NO recursive CTEs
❌ NO VARCHAR(MAX) — use VARCHAR(4000) max
❌ NO IDENTITY — use ROW_NUMBER() for surrogate keys
❌ NO ALTER TABLE DROP COLUMN — recreate table
❌ NO GETDATE()/SYSDATETIME() as column DEFAULT — constants only
❌ NO multi-row INSERT VALUES — use INSERT INTO...SELECT or COPY INTO
❌ NO SET ROWCOUNT — use TOP()
⚠️  PK/FK/UNIQUE constraints are NOT enforced
⚠️  Object names are case-sensitive
```

## 📐 Mandatory Code Structure

```sql
-- ==============================================================================
-- FABRIC WAREHOUSE SQL - SILVER LAYER (Dedup + DELETE/INSERT Upsert)
-- ==============================================================================
-- Generated by: Legacy2Lake UTM Platform - Agent C (Interpreter)
-- Source : {warehouse}.bronze.{TABLE_NAME}
-- Target : {warehouse}.silver.{TABLE_NAME}
-- Primary Keys : {pk_columns}
-- ⚠️  NO MERGE — Fabric Warehouse does not support MERGE statement
-- ==============================================================================

-- Step 1: Create Silver table if not exists
IF NOT EXISTS (
    SELECT 1 FROM sys.tables t
    JOIN sys.schemas s ON t.schema_id = s.schema_id
    WHERE s.name = 'silver' AND t.name = '{TABLE_NAME}'
)
BEGIN
    -- CTAS from Bronze (first load) — structure only with WHERE FALSE equivalent
    CREATE TABLE silver.{TABLE_NAME} AS
    SELECT TOP 0
        order_id,
        customer_id,
        CAST(order_date AS DATE)       AS order_date,
        CAST(amount AS DECIMAL(18,2))  AS amount,
        UPPER(LTRIM(RTRIM(status)))    AS status,
        -- Silver audit columns (MANDATORY)
        CAST(NULL AS DATETIME2)        AS _processed_at,
        CAST(NULL AS INT)              AS _quality_score,
        CAST(NULL AS VARCHAR(200))     AS _silver_source
    FROM bronze.{TABLE_NAME};
END;

-- Step 2: Build deduplicated + validated staging CTE
-- ✅ Simple CTEs are supported. Recursive CTEs are NOT.
;WITH deduplicated AS (
    SELECT
        order_id,
        customer_id,
        CAST(order_date AS DATE)       AS order_date,
        CAST(amount AS DECIMAL(18,2))  AS amount,
        UPPER(LTRIM(RTRIM(status)))    AS status,
        ROW_NUMBER() OVER (
            PARTITION BY order_id      -- PK(s)
            ORDER BY _ingestion_timestamp DESC
        ) AS _row_num
    FROM bronze.{TABLE_NAME}
    WHERE order_id IS NOT NULL         -- ✅ Filter NULL PKs
      AND customer_id IS NOT NULL
),
cleansed AS (
    SELECT
        order_id,
        customer_id,
        order_date,
        amount,
        status,
        -- Quality score: 20 pts per valid mandatory field
        CASE WHEN order_id IS NOT NULL THEN 20 ELSE 0 END
        + CASE WHEN customer_id IS NOT NULL THEN 20 ELSE 0 END
        + CASE WHEN amount > 0 THEN 20 ELSE 0 END
        + CASE WHEN order_date IS NOT NULL THEN 20 ELSE 0 END
        + CASE WHEN status IN ('PENDING','CONFIRMED','SHIPPED','DELIVERED') THEN 20 ELSE 0 END
        AS _quality_score
    FROM deduplicated
    WHERE _row_num = 1                 -- Keep latest per PK
      AND ISNULL(amount, 0) >= 0       -- Business rule: no negative amounts
      AND status IN ('PENDING','CONFIRMED','SHIPPED','DELIVERED')
)

-- Step 3: Upsert via DELETE + INSERT (Fabric Warehouse pattern for MERGE)
-- ⚠️ MERGE is NOT supported — this is the correct Fabric Warehouse alternative

-- 3a: Delete existing rows that will be updated
DELETE s
FROM silver.{TABLE_NAME} s
WHERE EXISTS (
    SELECT 1 FROM cleansed c
    WHERE c.order_id = s.order_id    -- Match on all PKs
);

-- 3b: Insert all new + updated rows from staging CTE
INSERT INTO silver.{TABLE_NAME} (
    order_id, customer_id, order_date, amount, status,
    _processed_at, _quality_score, _silver_source
)
SELECT
    order_id,
    customer_id,
    order_date,
    amount,
    status,
    CAST(GETUTCDATE() AS DATETIME2) AS _processed_at,
    _quality_score,
    'bronze.{TABLE_NAME}'           AS _silver_source
FROM cleansed;

-- Step 4: Verify result
SELECT
    COUNT(*)                             AS total_records,
    AVG(CAST(_quality_score AS FLOAT))   AS avg_quality_score,
    MAX(_processed_at)                   AS last_processed_at
FROM silver.{TABLE_NAME};
```

## ⚙️ Mandatory Requirements

### ✅ DELETE + INSERT Pattern (Fabric Upsert):
```sql
-- Step 1: Remove rows that will be refreshed
DELETE target FROM silver.table t
WHERE EXISTS (SELECT 1 FROM new_data n WHERE n.pk = t.pk);

-- Step 2: Insert all rows (new + refreshed)
INSERT INTO silver.table SELECT ... FROM new_data;
```
- ✅ Works in Fabric Warehouse
- ✅ Idempotent when run multiple times
- ⚠️ Not atomic — wrap in explicit transaction if needed

### ✅ Explicit Transaction (optional but recommended):
```sql
BEGIN TRANSACTION;
    DELETE s FROM silver.{TABLE_NAME} s
    JOIN cleansed c ON c.order_id = s.order_id;
    INSERT INTO silver.{TABLE_NAME} SELECT ... FROM cleansed;
COMMIT TRANSACTION;
```

### ✅ Deduplication:
- `ROW_NUMBER() OVER (PARTITION BY pks ORDER BY _ingestion_timestamp DESC)`
- Filter `_row_num = 1`
- Filter NULL PKs in WHERE clause

### ✅ Silver Audit Columns:
- `_processed_at` → `CAST(GETUTCDATE() AS DATETIME2)` (always UTC)
- `_quality_score` → Integer 0-100 per record
- `_silver_source` → `'bronze.{TABLE_NAME}'`

### ✅ PII Masking (if is_pii=true):
```sql
-- Hash: HASHBYTES returns VARBINARY — cast to VARCHAR for storage
CONVERT(VARCHAR(64), HASHBYTES('SHA2_256', LOWER(email)), 2) AS email,
-- Redact:
'REDACTED' AS phone_number
```
