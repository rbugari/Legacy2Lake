# 🏭 Microsoft Fabric Warehouse SQL - Gold Layer (Star Schema / Aggregations)

**Purpose:** Generate production-ready **Fabric Warehouse T-SQL** for Gold layer dimensional models and pre-aggregated KPI tables using **CTAS** and **TRUNCATE + INSERT** patterns, optimized for **Power BI Direct Lake** and **Power BI import mode** via Fabric Warehouse.

> 🚫 **CRITICAL:** Fabric Warehouse does NOT support `MERGE`, `IDENTITY`, or `VARCHAR(MAX)`. Gold tables are rebuilt via `TRUNCATE + INSERT` (not MERGE). Surrogate keys use `ROW_NUMBER()`, not `IDENTITY`.

---

## 🤖 Agent Instructions

You are an expert **Microsoft Fabric Warehouse Analytics Engineer** specializing in **Star Schema dimensional modeling** and **T-SQL analytics** on Fabric Warehouse. Generate production-ready Gold layer SQL entirely in Fabric-compatible T-SQL.

**Your code must:**
- Read from **Silver tables** (`silver.{TABLE_NAME}`)
- Implement **Star Schema** (FACT + DIMENSION) using **CTAS** or `TRUNCATE + INSERT`
- Apply **business logic** (CASE labels, computed metrics, surrogate keys via `ROW_NUMBER()`)
- Add **Gold audit columns**: `_gold_created_at`, `_grain_level`, `_refresh_time`
- Use `GETUTCDATE()` for all timestamps
- Optimize for **Power BI** consumption (simple aggregations, no complex nested CTEs)

### 🚫 FABRIC WAREHOUSE T-SQL HARD RESTRICTIONS:

```
❌ NO MERGE — use TRUNCATE + INSERT for Gold (rebuild pattern)
❌ NO IDENTITY — use ROW_NUMBER() for surrogate keys
❌ NO VARCHAR(MAX) — VARCHAR(4000) max safe
❌ NO DEFAULT GETDATE() on columns — populate via INSERT/UPDATE
❌ NO recursive CTEs
❌ NO triggers, NO materialized views
❌ NO ALTER TABLE DROP COLUMN — recreate table
❌ NO multi-row INSERT VALUES — use INSERT INTO ... SELECT
⚠️  PK/FK/UNIQUE constraints NOT enforced (declarative only)
⚠️  Object names case-sensitive
```

## 📐 Mandatory Code Structure

```sql
-- ==============================================================================
-- FABRIC WAREHOUSE SQL - GOLD LAYER (Star Schema, TRUNCATE + INSERT)
-- ==============================================================================
-- Generated by: Legacy2Lake UTM Platform - Agent C (Interpreter)
-- Source  : {warehouse}.silver.*
-- Target  : {warehouse}.gold.*
-- Type    : {DIMENSION | FACT | AGGREGATED_KPI}
-- ⚠️  NO MERGE — Gold uses TRUNCATE + INSERT (full rebuild pattern)
-- ⚠️  NO IDENTITY — surrogate keys via ROW_NUMBER()
-- ==============================================================================

-- ==============================================================================
-- DIMENSION TABLE: dim_customers
-- ==============================================================================
-- 1a: Create if not exists (CTAS first load)
IF NOT EXISTS (
    SELECT 1 FROM sys.tables t
    JOIN sys.schemas s ON t.schema_id = s.schema_id
    WHERE s.name = 'gold' AND t.name = 'dim_customers'
)
BEGIN
    CREATE TABLE gold.dim_customers AS
    SELECT TOP 0
        CAST(0 AS BIGINT)         AS customer_key,   -- Surrogate key (NO IDENTITY)
        CAST('' AS VARCHAR(50))   AS customer_id,    -- Business key
        CAST('' AS VARCHAR(200))  AS customer_name,
        CAST('' AS VARCHAR(200))  AS customer_email,
        CAST('' AS VARCHAR(50))   AS customer_country,
        CAST('' AS VARCHAR(20))   AS status_label,
        CAST('' AS VARCHAR(20))   AS customer_tier,
        CAST(NULL AS DATETIME2)   AS _gold_created_at,
        CAST('' AS VARCHAR(50))   AS _grain_level,
        CAST(NULL AS DATETIME2)   AS _refresh_time
    FROM silver.customers;
END;

-- 1b: Rebuild dimension (TRUNCATE + INSERT — Gold is always full rebuild)
-- ⚠️ NO MERGE — truncate and rebuild is the Fabric Warehouse Gold pattern
TRUNCATE TABLE gold.dim_customers;

INSERT INTO gold.dim_customers (
    customer_key, customer_id, customer_name, customer_email,
    customer_country, status_label, customer_tier,
    _gold_created_at, _grain_level, _refresh_time
)
SELECT
    -- Surrogate key via ROW_NUMBER (NO IDENTITY — not reliable in Fabric)
    ROW_NUMBER() OVER (ORDER BY c.customer_id) AS customer_key,

    c.customer_id,
    c.customer_name,
    c.email                                     AS customer_email,
    c.country                                   AS customer_country,

    -- Business label (CASE WHEN — no IIF() alternative but CASE is fine)
    CASE c.status
        WHEN 'A' THEN 'Active'
        WHEN 'I' THEN 'Inactive'
        ELSE 'Unknown'
    END                                         AS status_label,

    -- Customer segmentation tier
    CASE
        WHEN c.total_revenue > 10000 THEN 'VIP'
        WHEN c.total_revenue > 5000  THEN 'Premium'
        WHEN c.total_revenue > 1000  THEN 'Standard'
        ELSE 'Bronze'
    END                                         AS customer_tier,

    -- Gold audit columns (MANDATORY)
    CAST(GETUTCDATE() AS DATETIME2)             AS _gold_created_at,
    'customer'                                  AS _grain_level,
    CAST(GETUTCDATE() AS DATETIME2)             AS _refresh_time

FROM silver.customers c;

-- ==============================================================================
-- FACT TABLE: fact_orders
-- ==============================================================================
IF NOT EXISTS (
    SELECT 1 FROM sys.tables t
    JOIN sys.schemas s ON t.schema_id = s.schema_id
    WHERE s.name = 'gold' AND t.name = 'fact_orders'
)
BEGIN
    CREATE TABLE gold.fact_orders AS
    SELECT TOP 0
        CAST('' AS VARCHAR(50))   AS order_key,
        CAST(0 AS BIGINT)         AS customer_key,
        CAST(0 AS INT)            AS date_key,         -- YYYYMMDD integer
        CAST(NULL AS DATE)        AS order_date,
        CAST('' AS VARCHAR(20))   AS order_status,
        CAST(0 AS DECIMAL(18,2))  AS gross_amount,
        CAST(0 AS DECIMAL(18,2))  AS discount_amount,
        CAST(0 AS DECIMAL(18,2))  AS net_amount,
        CAST(0 AS DECIMAL(10,4))  AS net_margin_pct,
        CAST(0 AS BIT)            AS is_discounted,
        CAST(NULL AS DATETIME2)   AS _gold_created_at,
        CAST('' AS VARCHAR(50))   AS _grain_level,
        CAST(NULL AS DATETIME2)   AS _refresh_time
    FROM silver.orders;
END;

TRUNCATE TABLE gold.fact_orders;

INSERT INTO gold.fact_orders (
    order_key, customer_key, date_key, order_date, order_status,
    gross_amount, discount_amount, net_amount, net_margin_pct, is_discounted,
    _gold_created_at, _grain_level, _refresh_time
)
SELECT
    o.order_id                                            AS order_key,
    c.customer_key,                                                    -- FK → dim_customers

    -- Date key (YYYYMMDD integer for DIM_DATE join)
    CAST(FORMAT(o.order_date, 'yyyyMMdd') AS INT)         AS date_key,
    o.order_date,
    o.status                                              AS order_status,

    o.amount                                              AS gross_amount,
    ISNULL(o.discount, 0)                                 AS discount_amount,
    o.amount - ISNULL(o.discount, 0)                      AS net_amount,

    -- Safe division — check denominator before dividing
    CASE WHEN o.amount = 0 THEN 0
         ELSE CAST((o.amount - ISNULL(o.discount, 0)) AS DECIMAL(18,4)) / CAST(o.amount AS DECIMAL(18,4))
    END                                                   AS net_margin_pct,

    CASE WHEN ISNULL(o.discount, 0) > 0 THEN 1 ELSE 0 END AS is_discounted,

    -- Gold audit columns
    CAST(GETUTCDATE() AS DATETIME2)                       AS _gold_created_at,
    'order'                                               AS _grain_level,
    CAST(GETUTCDATE() AS DATETIME2)                       AS _refresh_time

FROM silver.orders o
JOIN gold.dim_customers c ON o.customer_id = c.customer_id;

-- ==============================================================================
-- AGGREGATED KPI TABLE: gold_daily_sales_summary (Power BI optimized)
-- ==============================================================================
IF NOT EXISTS (
    SELECT 1 FROM sys.tables t
    JOIN sys.schemas s ON t.schema_id = s.schema_id
    WHERE s.name = 'gold' AND t.name = 'daily_sales_summary'
)
BEGIN
    CREATE TABLE gold.daily_sales_summary AS
    SELECT TOP 0
        CAST(NULL AS DATE)          AS order_date,
        CAST('' AS VARCHAR(20))     AS customer_tier,
        CAST('' AS VARCHAR(50))     AS customer_country,
        CAST(0 AS INT)              AS total_orders,
        CAST(0 AS INT)              AS unique_customers,
        CAST(0 AS DECIMAL(18,2))    AS gross_sales,
        CAST(0 AS DECIMAL(18,2))    AS total_discounts,
        CAST(0 AS DECIMAL(18,2))    AS net_sales,
        CAST(0 AS DECIMAL(18,2))    AS avg_order_value,
        CAST(0 AS DECIMAL(18,2))    AS revenue_per_order,
        CAST(NULL AS DATETIME2)     AS _gold_created_at,
        CAST('' AS VARCHAR(50))     AS _grain_level,
        CAST(NULL AS DATETIME2)     AS _refresh_time
    FROM gold.fact_orders f
    JOIN gold.dim_customers c ON f.customer_key = c.customer_key;
END;

TRUNCATE TABLE gold.daily_sales_summary;

INSERT INTO gold.daily_sales_summary
SELECT
    f.order_date,
    c.customer_tier,
    c.customer_country,
    COUNT(DISTINCT f.order_key)                           AS total_orders,
    COUNT(DISTINCT f.customer_key)                        AS unique_customers,
    SUM(f.gross_amount)                                   AS gross_sales,
    SUM(f.discount_amount)                                AS total_discounts,
    SUM(f.net_amount)                                     AS net_sales,
    CASE WHEN COUNT(f.order_key) = 0 THEN 0
         ELSE SUM(f.net_amount) / COUNT(f.order_key) END  AS avg_order_value,
    CASE WHEN COUNT(DISTINCT f.order_key) = 0 THEN 0
         ELSE SUM(f.net_amount) / COUNT(DISTINCT f.order_key) END
                                                          AS revenue_per_order,
    CAST(GETUTCDATE() AS DATETIME2)                       AS _gold_created_at,
    'daily_by_tier_country'                               AS _grain_level,
    CAST(GETUTCDATE() AS DATETIME2)                       AS _refresh_time
FROM gold.fact_orders f
JOIN gold.dim_customers c ON f.customer_key = c.customer_key
GROUP BY
    f.order_date,
    c.customer_tier,
    c.customer_country;

-- Verify
SELECT COUNT(*) AS total_rows, MAX(_refresh_time) AS last_refresh
FROM gold.daily_sales_summary;
```

## ⚙️ Mandatory Requirements

### ✅ Gold Rebuild Pattern (TRUNCATE + INSERT):
- **Always** `TRUNCATE TABLE gold.{TABLE}` before INSERT (full rebuild)
- Never use MERGE (not supported)
- Safe for Gold because it's rebuilt from Silver on each run

### ✅ Surrogate Keys (NO IDENTITY):
```sql
-- ✅ CORRECT: ROW_NUMBER() for surrogate keys
ROW_NUMBER() OVER (ORDER BY natural_key) AS surrogate_key

-- ❌ WRONG: IDENTITY is unreliable in Fabric distributed environment
-- customer_key INT IDENTITY(1,1)
```

### ✅ Safe Division (no DIV0 function in Fabric SQL):
```sql
-- ✅ CORRECT: Manual NULL/zero guard
CASE WHEN denominator = 0 THEN 0 ELSE numerator / denominator END

-- ❌ WRONG: DIV0() does not exist in Fabric Warehouse T-SQL
```

### ✅ Gold Audit Columns:
- `_gold_created_at` → `CAST(GETUTCDATE() AS DATETIME2)` (UTC always)
- `_grain_level` → varchar describing grain (e.g., `'daily_by_tier_country'`)
- `_refresh_time` → `CAST(GETUTCDATE() AS DATETIME2)`
