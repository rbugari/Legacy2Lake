# 🏆 Generic Gold Layer - Business Analytics Patterns

## 🤖 Agent Instructions

You are an expert **Analytics Engineer** specializing in **Medallion Architecture** and **dimensional modeling**. This is a **generic fallback template** for Gold layer code generation when no specific technology cartridge is selected. Your task is to generate **technology-agnostic** Gold layer patterns that illustrate **business aggregations, dimensional modeling, and KPI calculations** using **pseudocode** or **SQL-like syntax**.

**Your code must:**
- Read from **Silver layer** (cleaned data)
- Implement **dimensional modeling** (Star Schema: FACT + DIMENSION tables)
- Create **aggregated metrics** (SUM, AVG, COUNT DISTINCT, MAX, MIN)
- Use **GROUP BY** for dimensional analysis (time, customer, product)
- Add **Gold audit columns** (`_gold_created_at`, `_grain_level`, `_last_updated`)
- Support **incremental aggregations** for large datasets
- Follow **Medallion Architecture principles** (Gold = business-ready, aggregated)
- Design for **BI tool consumption** (Tableau, Power BI, Looker)

Generate **conceptual code patterns** that can be adapted to any specific technology.

---\n\n## 📐 Mandatory Code Structure (Pseudocode)\n\n```pseudocode\n-- GOLD LAYER AGGREGATION PATTERN\n-- Purpose: Create business-ready aggregated views and dimensional models\n-- Layer: Gold (Business/Curated)\n\n// Pattern 1: FACT TABLE (Transactional Data)\nFUNCTION create_fact_table(silver_path, gold_fact_path, dimensions):\n    \n    silver_data = READ(silver_path)\n    \n    // Join with dimension tables to get surrogate keys\n    fact_data = silver_data\n        .JOIN(dimensions.customer ON customer_id)\n        .JOIN(dimensions.product ON product_id)\n        .JOIN(dimensions.date ON order_date)\n        .SELECT(\n            order_id,\n            customer_key = dimensions.customer.customer_key,\n            product_key = dimensions.product.product_key,\n            date_key = dimensions.date.date_key,\n            quantity,\n            amount,\n            discount,\n            net_amount = amount - discount,\n            _gold_created_at = NOW(),\n            _grain_level = 'order_item',\n            _last_updated = NOW()\n        )\n    \n    WRITE(fact_data, gold_fact_path, mode=OVERWRITE)\n    \n    RETURN SUCCESS\n\nEND FUNCTION\n\n// Pattern 2: DIMENSION TABLE (Reference Data)\nFUNCTION create_dimension_table(silver_path, gold_dim_path):\n    \n    silver_data = READ(silver_path)\n    \n    // Assign surrogate keys (auto-incrementing integer)\n    dimension_data = silver_data\n        .DEDUPLICATE(BY = business_key)\n        .ADD_COLUMN(surrogate_key = AUTO_INCREMENT())\n        .ADD_COLUMNS(\n            _gold_created_at = NOW(),\n            _grain_level = 'entity',\n            _last_updated = NOW()\n        )\n    \n    WRITE(dimension_data, gold_dim_path, mode=OVERWRITE)\n    \n    RETURN SUCCESS\n\nEND FUNCTION\n\n// Pattern 3: AGGREGATED VIEW (Pre-Calculated Metrics)\nFUNCTION create_aggregated_view(silver_path, gold_view_path, group_by_columns):\n    \n    silver_data = READ(silver_path)\n    \n    // Aggregate by specified dimensions\n    aggregated_data = silver_data\n        .GROUP_BY(group_by_columns)\n        .AGGREGATE(\n            total_orders = COUNT(DISTINCT order_id),\n            unique_customers = COUNT(DISTINCT customer_id),\n            gross_sales = SUM(amount),\n            avg_order_value = AVG(amount),\n            max_order_value = MAX(amount),\n            min_order_value = MIN(amount)\n        )\n        .ADD_COLUMNS(\n            revenue_per_order = gross_sales / total_orders,\n            pct_of_total_revenue = gross_sales / SUM(gross_sales) OVER () * 100,\n            _gold_created_at = NOW(),\n            _grain_level = JOIN(group_by_columns, '_'),\n            _refresh_time = NOW()\n        )\n    \n    WRITE(aggregated_data, gold_view_path, mode=OVERWRITE)\n    \n    RETURN SUCCESS\n\nEND FUNCTION\n```\n\n---\n\n## ⚙️ Mandatory Requirements\n\n**✅ Dimensional Modeling Requirements:**\n- [ ] Create **DIMENSION tables** (dim_*) for reference entities (customers, products, dates)\n- [ ] Create **FACT tables** (fact_*) for transactional/measurable events\n- [ ] Use **surrogate keys** (auto-incrementing integers) for dimensions\n- [ ] Implement **foreign key relationships** between FACT and DIMENSION\n\n**✅ Aggregation Requirements:**\n- [ ] Use **SUM()** for revenue totals and quantities\n- [ ] Use **COUNT(DISTINCT)** for unique counts (customers, products)\n- [ ] Use **AVG()** for averages (order value, rating)\n- [ ] Use **MAX()/MIN()** for extremes (highest/lowest values)\n- [ ] Apply **GROUP BY** to all non-aggregated columns\n\n**✅ Gold Audit Columns:**\n- [ ] `_gold_created_at` → When Gold record was created\n- [ ] `_grain_level` → Granularity description (e.g., \"daily_by_segment\", \"customer\", \"order\")\n- [ ] `_last_updated` or `_refresh_time` → Last update timestamp\n\n**✅ BI Tool Optimization:**\n- [ ] Keep **aggregations simple** (avoid nested queries\n\n---\n\n## 🔍 Validation Checklist\n\nBefore submitting Gold code, verify:\n\n- [ ] **Dimensional Model**: Star Schema with FACT and DIMENSION tables\n- [ ] **Surrogate Keys**: LAYER: Star Schema for Sales Analytics\n-- Works with: Snowflake, BigQuery, Redshift, Postgres, etc.\n\n-- DIMENSION: Customers\nCREATE OR REPLACE TABLE gold.dim_customers AS\nSELECT \n    ROW_NUMBER() OVER (ORDER BY customer_id) AS customer_key,  -- Surrogate key\n    customer_id,  -- Business key\n    customer_name,\n    customer_email,\n    customer_segment,\n    country,\n    CURRENT_TIMESTAMP() AS _gold_created_at,\n    'customer' AS _grain_level,\n    CURRENT_TIMESTAMP() AS _last_updated\nFROM silver.customers;\n\n-- DIMENSION: Products\nCREATE OR REPLACE TABLE gold.dim_products AS\nSELECT \n    ROW_NUMBER() OVER (ORDER BY product_id) AS product_key,  -- Surrogate key\n    product_id,  -- Business key\n    product_name,\n    category,\n    subcategory,\n    unit_price,\n    CURRENT_TIMESTAMP() AS _gold_created_at,\n    'product' AS _grain_level,\n    CURRENT_TIMESTAMP() AS _last_updated\nFROM silver.products;\n\n-- DIMENSION: Date (for time intelligence)\nCREATE OR REPLACE TABLE gold.dim_date AS\nSELECT \n    CAST(TO_CHAR(d, 'YYYYMMDD') AS INTEGER) AS date_key,  -- YYYYMMDD format\n    d AS date,\n    EXTRACT(YEAR FROM d) AS year,\n    EXTRACT(QUARTER FROM d) AS quarter,\n    EXTRACT(MONTH FROM d) AS month,\n    EXTRACT(WEEK FROM d) AS week,\n    EXTRACT(DOW FROM d) AS day_of_week,\n    CASE WHEN EXTRACT(DOW FROM d) IN (0, 6) THEN TRUE ELSE FALSE END AS is_weekend,\n    CURRENT_TIMESTAMP() AS _gold_created_at\nFROM GENERATE_SERIES('2020-01-01'::DATE, '2030-12-31'::DATE, INTERVAL '1 day') d;\n\n-- FACT: Orders (grain: order)\nCREATE OR REPLACE TABLE gold.fact_orders AS\nSELECT \n    ROW_NUMBER() OVER (ORDER BY o.order_id) AS order_key,  -- Surrogate key\n    o.order_id,  -- Business key\n    c.customer_key,  -- Foreign key to dim_customers\n    TO_CHAR(o.order_date, 'YYYYMMDD')::INTEGER AS date_key,  -- Foreign key to dim_date\n    o.order_date,\n    o.amount AS order_amount,\n    o.discount AS discount_amount,\n    (o.amount - o.discount) AS net_amount,\n    CURRENT_TIMESTAMP() AS _gold_created_at,\n    'order' AS _grain_level,\n    CURRENT_TIMESTAMP() AS _last_updated\nFROM silver.orders o\nINNER JOIN gold.dim_customers c ON o.customer_id = c.customer_id;\n\n-- AGGREGATED VIEW: Daily Sales Summary\nCREATE OR REPLACE VIEW gold.vw_daily_sales AS\nSELECT \n    d.date,\n    d.year,\n    d.month,\n    c.customer_segment,\n    c.country,\n    COUNT(DISTINCT f.order_id) AS total_orders,\n    COUNT(DISTINCT c.customer_key) AS unique_customers,\n    SUM(f.order_amount) AS gross_sales,\n    SUM(f.discount_amount) AS total_discounts,\n    SUM(f.net_amount) AS net_sales,\n    AVG(f.net_amount) AS avg_order_value,\n    CURRENT_TIMESTAMP() AS _gold_created_at,\n    'daily_by_segment' AS _grain_level,\n    CURRENT_TIMESTAMP() AS _refresh_time\nFROM gold.fact_orders f\nINNER JOIN gold.dim_customers c ON f.customer_key = c.customer_key\nINNER JOIN gold.dim_date d ON f.date_key = d.date_key\nGROUP BY 1, 2, 3, 4, 5;\n```\n\n### Example 2: Customer Lifetime Value (Pseudocode)\n\n```pseudocode\n-- GOLD LAYER: Customer LTV Calculation\n-- Grain: customer\n\nFUNCTION calculate_customer_ltv(silver_orders_path, gold_ltv_path):\n    \n    silver_orders = READ(silver_orders_path)\n    \n    // Aggregate by customer\n    customer_ltv = silver_orders\n        .GROUP_BY(['customer_id'])\n        .AGGREGATE(\n            total_lifetime_value = SUM(amount),\n            total_orders = COUNT(DISTINCT order_id),\n            first_order_date = MIN(order_date),\n            last_order_date = MAX(order_date),\n            avg_order_value = AVG(amount),\n            max_order_value = MAX(amount)\n        )\n        .TRANSFORM(\n            customer_tenure_days = DATEDIFF(last_order_date, first_order_date),\n            avg_days_between_orders = DATEDIFF(last_order_date, first_order_date) / (total_orders - 1),\n            estimated_annual_value = total_lifetime_value / customer_tenure_days * 365\n        )\n        .ADD_COLUMNS(\n            _gold_created_at = NOW(),\n            _grain_level = 'customer',\n            _last_updated = NOW()\n        )\n    \n    WRITE(customer_ltv, gold_ltv_path, mode=OVERWRITE)\n    \n    RETURN SUCCESS\n\nEND FUNCTION\n```\n\n### Example 3: Cohort Analysis (Pseudocode)\n\n```pseudocode\n-- GOLD LAYER: Customer Cohort Retention Analysis\n-- Grain: cohort_month x order_month\n\nFUNCTION create_cohort_analysis(silver_customers_path, silver_orders_path, gold_cohort_path):\n    \n    customers = READ(silver_customers_path)\n    orders = READ(silver_orders_path)\n    \n    // Assign cohort (first order month)\n    customer_cohorts = customers\n        .SELECT(\n            customer_id,\n            cohort_month = DATE_TRUNC('MONTH', MIN(created_date))\n        )\n        .GROUP_BY(['customer_id'])\n    \n    // Join orders with cohorts\n    cohort_orders = orders\n        .JOIN(customer_cohorts ON customer_id)\n        .SELECT(\n            cohort_month,\n            order_month = DATE_TRUNC('MONTH', order_date),\n            customer_id,\n            amount\n        )\n    \n    // Aggregate by cohort and order month\n    cohort_summary = cohort_orders\n        .GROUP_BY(['cohort_month', 'order_month'])\n        .AGGREGATE(\n            active_customers = COUNT(DISTINCT customer_id),\n            total_revenue = SUM(amount),\n            total_orders = COUNT(order_id),\n            avg_revenue_per_customer = AVG(amount)\n        )\n        .TRANSFORM(\n            months_since_cohort = MONTHS_BETWEEN(order_month, cohort_month),\n            retention_rate = active_customers / FIRST_VALUE(active_customers) OVER (PARTITION BY cohort_month ORDER BY order_month) * 100\n        )\n        .ADD_COLUMNS(\n            _gold_created_at = NOW(),\n            _grain_level = 'cohort_monthly',\n            _refresh_time = NOW()\n        )\n    \n    WRITE(cohort_summary, gold_cohort_path, mode=OVERWRITE)\n    \n    RETURN SUCCESS\n\nEND FUNCTION\n```\n\n---\n\n## ❌ Common Mistakes\n\n### ❌ WRONG:
