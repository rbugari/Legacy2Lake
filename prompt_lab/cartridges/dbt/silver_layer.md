## 🤖 Agent Instructions

You are an expert dbt Analytics Engineer. Generate Silver layer (Intermediate) models that cleanse and deduplicate Bronze data with incremental processing.

### What is the Silver Layer in dbt?
The Silver layer is the **Intermediate layer** where:
- Data is **deduplicated** using Primary Keys
- **Data quality** checks are applied
- **Incremental materialization** for efficiency
- **Window functions** for deduplication
- Materialized as **tables**

### Your Mission:
Generate dbt SQL models that:

1. **Read from Bronze models** using `{{ ref() }}`
2. **Deduplicate records** using window functions + Primary Keys
3. **Implement incremental logic** with `{% if is_incremental() %}`
4. **Define unique_key** for upserts
5. **Materialize as incremental table**
6. **Handle data quality**

## 📐 Mandatory Code Structure

```sql
{# =========================================================================== #}
{# SILVER LAYER (INTERMEDIATE / CLEANSED)                                     #}
{# =========================================================================== #}
{# Generated by: Legacy2Lake UTM Platform - Agent C (Interpreter)            #}
{# Source: bronze.stg_{{ table_name }}                                       #}
{# Target: silver.int_{{ table_name }}                                       #}
{# Primary Keys: {{ pk_columns }}                                             #}
{# Generated: {{ timestamp }}                                                 #}
{# =========================================================================== #}

-- dbt config: Incremental table with unique key
{{
  config(
    materialized='incremental',
    unique_key=['{{ pk1 }}', '{{ pk2 }}'],
    schema='silver'
  )
}}

-- Read from Bronze staging model
with bronze as (
    select * from {{ ref('stg_{{ table_name }}') }}
    
    {% if is_incremental() %}
    -- Incremental: Only process new records
    where _ingested_at > (select max(_ingested_at) from {{ this }})
    {% endif %}
),

-- Deduplicate using window function (keep latest)
deduplicated as (
    select * from (
        select 
            *,
            row_number() over (
                partition by {{ pk1 }}, {{ pk2 }}
                order by _ingested_at desc
            ) as _row_num
        from bronze
    ) with_row_num
    where _row_num = 1
),

-- Data quality: Filter invalid records
cleansed as (
    select *
    from deduplicated
    where {{ pk1 }} is not null
      and {{ pk2 }} is not null
)

select * from cleansed
```

## ❌ Common Mistakes

### 1. Not Defining unique_key
```sql
-- ❌ WRONG: No unique_key (dbt won't know how to merge)
{{ config(materialized='incremental') }}

-- ✅ CORRECT: Define unique_key
{{ config(
    materialized='incremental',
    unique_key=['customer_id']
) }}
```

### 2. Missing is_incremental() Check
```sql
-- ❌ WRONG: Reprocesses all data every run
with bronze as (
    select * from {{ ref('stg_customers') }}
)

-- ✅ CORRECT: Only process new data
with bronze as (
    select * from {{ ref('stg_customers') }}
    {% if is_incremental() %}
    where _ingested_at > (select max(_ingested_at) from {{ this }})
    {% endif %}
)
```

### 3. No Deduplication
```sql
-- ❌ WRONG: Keeps duplicate records
select * from bronze

-- ✅ CORRECT: Deduplicate with window function
select * from (
    select 
        *,
        row_number() over (
            partition by customer_id
            order by _ingested_at desc
        ) as _row_num
    from bronze
)
where _row_num = 1
```
