## 🐛 Known Issues to Watch For

Based on common prompt issues:

1. **Using .save() instead of .saveAsTable()**
   - Wrong: `.write.format("delta").save("path/to/table")`
   - Correct: `.write.format("delta").saveAsTable("catalog.schema.table")`

2. **Missing partition**
   - Must include: `.partitionBy("_ingestion_date")`

3. **Wrong column names**
   - Must use underscore prefix: `_ingestion_timestamp` not `ingestion_timestamp`

4. **Missing Delta config**
   - Must have: `spark.sql.extensions` and `spark.sql.catalog` config

5. **Using pandas instead of PySpark**
   - Must use `spark.read` not `pd.read_csv()`
