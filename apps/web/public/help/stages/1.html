Triage Phase
AI-assisted classification of every discovered asset
🎯 What this stage does
The Triage Phase uses an AI agent to analyze every object from Stage 0 and assign it a migration role, a load strategy, and a risk level. You can review, override, and fine-tune every AI decision before proceeding to code generation.
⚙️ Object Classification
CORE
Critical objects fully migrated and translated to the target platform.
SUPPORT
Auxiliary objects migrated as-is or with minimal transformation.
IGNORED
Excluded from migration — deprecated tables, dev-only artifacts.
⚙️ Load Strategies
Strategy Behaviour
Full Load Full refresh on every pipeline run.
Incremental Only new or changed records are loaded per run.
SCD Type 2 Tracks historical changes with version rows.
Truncate & Load Clears and fully reloads the target on each run.
▶️ Actions
🤖
Run Analysis
Executes the Triage Agent to evaluate all assets, classify them, assign load strategies, and flag PII risks.
💾
Save Triage State
Manually saves your overrides and customizations from the Grid view.
💡 You can re-run the Triage Agent at any time. Your manual overrides are preserved unless you explicitly reset them.
📊 Views & Reports
View Description

Grid Spreadsheet-like table to bulk-edit classifications, strategies, and PII tags.
Schema Side-by-side view of legacy schema vs. proposed target schema.
Mapping Field-level column mapping between source and destination objects.
Origin Breakdown by source system — useful for multi-system migrations.

Source Queries Shows the underlying SQL logic for views and procedures.
