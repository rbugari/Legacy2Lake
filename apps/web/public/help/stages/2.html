Drafting Phase
Automated 1:1 code generation from your legacy objects
🎯 What this stage does
The Drafting Phase translates every CORE and SUPPORT asset from Triage into target-platform code — PySpark jobs, Snowpark scripts, SQL transformations, or whatever your Cartridge specifies. The goal is to make it work, not to make it perfect. The generated code faithfully preserves all transformations, business rules, and dependencies.
⚙️ What you can configure
Setting Description
Target Platform The destination tech stack — PySpark, Snowpark, Databricks, BigQuery SQL, etc.
Output Format File naming conventions and folder structure of generated output files.
Dialect Rules Platform-specific SQL/Python syntax adjustments applied during generation.
Cartridge Prompt Fine-tune the AI generation prompt: logging verbosity, error handling patterns, naming conventions.
Target Schema Review the proposed schema structure in the destination environment before running generation.
▶️ Actions
🏭
Run Pipeline
Launches the Drafting Agent, which iterates through every triaged asset and generates the corresponding target code file. Progress is shown in real time.
💡 You can re-run the pipeline after adjusting the cartridge prompt without losing manually reviewed files.
📊 Reports & Views
View Description
Pipeline Status Real-time progress — how many objects have been generated vs. total.
Execution Logs Detailed logs per object. Shows warnings for unsupported constructs.
Generation Summary Aggregated stats: total files, success rate, warning count.
Output Files Browse all generated code files organized by object type.
Generation Stats Quality metrics of the generated code — complexity, line counts, coverage.
