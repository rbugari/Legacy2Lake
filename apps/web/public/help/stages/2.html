Stage 2

Drafting

Drafting generates the first working target baseline. The goal is not perfect redesign. The goal is a useful implementation that can be reviewed, improved, and governed.

Start here

Use Overview to decide whether to run the pipeline, inspect outputs, or adjust cartridge settings.

Main action

Run Pipeline to generate the target artifacts approved by Triage.

Why it matters

This is the baseline that Refinement and Governance will build on.

What to review

  • Pipeline Status and Logs while Drafting is running
  • Generation Summary after completion
  • Output Files to inspect generated artifacts
  • Cartridge Settings before re-running

Common mistake

Treating Drafting as the final answer instead of a reviewable baseline.

Before you continue

Make sure the main files exist, the output looks coherent, and the team is ready to refine rather than regenerate blindly.
