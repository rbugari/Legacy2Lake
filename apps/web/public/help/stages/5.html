Handover Phase
Package, export, and deliver the complete migration output
🎯 What this stage does
The Handover Phase is the final stage of the Legacy2Lake pipeline. It bundles all migration artifacts — generated code, documentation, lineage maps, and the certification report — into a structured Handover Package ready for delivery to the target team or deployment environment.
⚙️ Export options
Option Description
Code Files Include all refined target-platform scripts (PySpark, Snowpark, SQL, etc.).
Documentation Include Technical Docs, Data Dictionary, Lineage Map, and Runbook.
Certification Report Attach the formal audit/certification summary for sign-off.
Manifest File A machine-readable JSON manifest of all packaged artifacts and their metadata.
Export Format ZIP archive, Git commit, or cloud storage upload (S3, Azure Blob, GCS).
▶️ Actions
📦
Export Options
Opens the export configuration panel. Select your desired output format and content scope, then confirm to generate and download the Handover Package.
💡 The Handover Package is immutable once generated. To apply changes, return to the relevant stage and regenerate.

🎉 Migration Complete!

The Handover Package has been generated and delivered. The receiving team should:
  1. Deploy the generated code to the target environment.
  2. Follow the Runbook to validate the first full pipeline run.
  3. Verify data quality against source using the Data Dictionary.
  4. Archive the package for audit trail purposes.
