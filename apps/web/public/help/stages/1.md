# Triage Phase

> Stage 1 of 5. Triage decides what matters, how it should be treated, and what deserves generation.

## Start here

This phase now lands on an **Overview** page first. Use it to:

- see whether triage has already run
- jump into the workbench views
- launch analysis when the phase has not started
- review context and file explorer without losing orientation

## What this stage does

Triage turns discovery output into a migration work plan. It classifies assets, highlights sensitive data, and builds the main mesh used downstream.

The point of Triage is not just classification. It is to make the next phase safer by deciding:

- what is `CORE`
- what is `SUPPORT`
- what is `IGNORED`
- what needs special handling
- what should be reviewed before generation

## What you can review and refine

| Area | Why it matters |
|---|---|
| **Graph** | Understand dependencies and object relationships. |
| **Grid** | Review and adjust classifications, strategy, and key metadata. |
| **Schema / Mapping** | Check structural interpretation before code generation. |
| **PII Detection** | Confirm sensitive fields and likely governance hotspots. |
| **Business Context** | Add project-specific rules or missing domain knowledge. |

## Main action

- **Run Analysis**: executes the triage workflow and populates the mesh and classification outputs.

You can re-run Triage after changing context or classifications.

## Views you should use

| View | When to use it |
|---|---|
| **Overview** | Best landing page for the phase. |
| **Grid** | Main operational view for reviewing classifications. |
| **Graph** | Best for dependency understanding and structural sanity-checks. |
| **Schema / Mapping** | Use before approving Drafting, especially for table-heavy projects. |
| **Execution Logs** | Use when triage results look incomplete or inconsistent. |

## Done when

Triage is ready when:

- important assets are classified correctly
- obvious `IGNORED` or `SUPPORT` decisions are no longer noisy
- PII and sensitive structures were reviewed
- the team is comfortable approving Drafting
