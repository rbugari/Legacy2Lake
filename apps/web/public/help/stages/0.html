Forensic scan & complete asset inventory
🎯 What this stage does
The Discovery Phase performs a deep forensic scan of your legacy codebase. It catalogs every object — tables, views, stored procedures, functions, triggers, and their inter-dependencies — without touching or moving any business data. The result is a structured inventory that powers every subsequent stage automatically.

▶️ Actions
🚀
Run Forensic Scan
Launches Agent S, which parses all uploaded files, extracts object metadata, builds the dependency node graph, and delivers the final inventory count.
💡 You can upload multiple files and re-run the scan at any time without losing previous results.
