Stage 0

Discovery

Discovery exists to reduce uncertainty before the project moves into classification and generation. It tells you what was actually ingested, what looks usable, and what is still missing.

Start here

Open Overview first. Use it to see status, score, file counts, and whether more context is needed before running the scan.

Main action

Run Forensic Scan when repository contents and support files are ready to be analyzed.

Why it matters

A weak Discovery usually creates noisy Triage and weaker generation later.

What to review

  • Forensic Assessment for viability and blockers
  • Tech Validation to confirm detected source technology
  • File Pre-Classification to inspect what the platform recognized
  • Execution Logs when the scan looks slow or suspicious

Common mistake

Moving into Triage without checking whether Discovery actually understood the source correctly.

Before you continue

Make sure the inventory count, detected technology, and key blockers all look reasonable.
