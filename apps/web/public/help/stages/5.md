# Handover Phase

> Stage 5 of 5. Handover packages and exports the final delivery set.

## Start here

Handover lands on an **Overview / Handover Package** page. Use it to:

- review package readiness
- inspect artifact counts
- export delivery or governance bundles
- prepare handoff to the receiving team

## What this stage does

Handover turns the project outputs into deliverables. It is the packaging layer for:

- generated code
- governance outputs
- delivery bundles
- optional repository push workflows

## What you can configure

| Area | What it controls |
|---|---|
| **Export variables** | Delivery-time variables and packaging context. |
| **Cartridge / export type** | Which package flavor you want to produce. |
| **GitHub push settings** | Optional repository delivery path when used. |

## Main actions

- **Export Delivery Bundle**
- **Export Governance Bundle**
- **Push To GitHub** when repository-based handoff is part of the workflow

## Views you should use

| View | When to use it |
|---|---|
| **Overview / Handover Package** | Best landing page for the phase. |

## Done when

Handover is complete when:

- the required package was exported successfully
- the receiving team has the right delivery bundle
- there are no open findings that require going back to a previous phase
