Refinement Phase
Optimization, quality review, and schema validation
🎯 What this stage does
The Refinement Phase takes the raw generated code from Drafting and systematically improves it. The AI agent reviews each file for performance anti-patterns, applies target platform best practices, and validates schema alignment. After refinement, each file is significantly closer to production-ready.
⚙️ What you can configure
Setting Description
Optimization Level How aggressively to refactor — conservative, standard, or aggressive.
Target Patterns Specific design patterns to enforce: partitioning by date, medallion architecture, etc.
Preserve Comments Whether to keep original inline comments from the legacy code.
Cartridge Prompts Customize AI instructions for style decisions and naming conventions during refinement.
▶️ Actions
✨
Run Refinement
Executes the Refinement Agent over all previously generated files. Only files that pass quality checks are updated in place.
⚠️ Running Refinement overwrites the Drafting output. Review the Generation Summary before proceeding.
