Governance Phase
Documentation, lineage, and compliance certification
🎯 What this stage does
The Governance Phase generates the complete documentation artifact for your migration project. It produces regulatory-ready reports and a full data lineage map tracing every object from source to destination. This phase ensures the migration is auditable, traceable, and defensible — critical for regulated industries and enterprise data governance.
▶️ Actions
📄
Generate Governance Report
Runs the Governance Agent to produce Technical Docs, Data Dictionary, Lineage Maps, and the Runbook.
🛡️
Run Audit / Certification
Validates all migration deliverables against a certification checklist. Produces a formal PASS/FAIL report suitable for stakeholder sign-off.
💡 Run the Governance Report first, then the Audit. The Audit uses the generated documentation as its input.
📊 Reports & Views
Report Description
Completion Status Dashboard showing the overall completion percentage of the migration project.
Technical Docs Full technical documentation per migrated object — inputs, outputs, logic, and dependencies.
Data Dictionary Business-friendly glossary of all fields, tables, and their definitions.
Lineage Map End-to-end data lineage visualization — from raw source tables to final target models.
Runbook Step-by-step operational guide for running, monitoring, and maintaining the migrated pipeline.
✅ Done when: The Certification Report shows a PASS status across all checklist items and all documentation artifacts are generated without errors. Proceed to Handover →
