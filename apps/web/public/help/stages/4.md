# 📋 Governance Phase

> **Stage 4 of 5** · Automated documentation, lineage, and compliance certification.

---

## 🎯 What this stage does

The **Governance Phase** generates the complete documentation artifact for your migration project. It produces regulatory-ready reports and a full **data lineage map** tracing every object from source to destination.

This phase ensures the migration is **auditable, traceable, and defensible** — critical for regulated industries and enterprise data governance requirements.

---

## ⚙️ What you can configure

There are no manual configuration steps in this phase. The content of all reports is derived automatically from the previous stages. However, you can trigger two distinct actions:

- **Generate Governance Report** — Produces the comprehensive documentation set.
- **Run Audit / Certification** — Executes a formal validation checklist to certify the migration meets predefined quality and compliance thresholds.

---

## ▶️ Actions

| Action | Description |
|---|---|
| **Generate Governance Report** | Runs the Governance Agent to produce technical docs, the data dictionary, lineage maps, and the runbook. |
| **Run Audit / Certification** | Validates all migration deliverables against a certification checklist. Produces a pass/fail report. |

> 💡 Run the Governance Report first, then the Audit. The Audit uses the generated documentation as its input.

---

## 📊 Reports & Views

| Report | Description |
|---|---|
| **Completion Status** | Dashboard showing the overall completion percentage of the migration project. |
| **Technical Docs** | Full technical documentation of every migrated object — inputs, outputs, logic, and dependencies. |
| **Data Dictionary** | Business-friendly glossary of all fields, tables, and their definitions. |
| **Lineage Map** | End-to-end data lineage visualization — from raw source tables to final target models. |
| **Runbook** | Step-by-step operational guide for running, monitoring, and maintaining the migrated pipeline. |

---

## ✅ Done when...

The **Certification Report** shows a **PASS** status across all checklist items, and all four documentation artifacts are generated without errors. Proceed to **Handover** to package and deliver the migration.
