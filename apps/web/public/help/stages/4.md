# Governance Phase

> Stage 4 of 5. Governance reviews the generated solution and produces the auditable delivery view.

## Start here

Governance now lands on an **Overview / Report** entry point. Use it to:

- decide whether to start governance
- review the certification result once finished
- switch to logs when the phase is running

## What this stage does

Governance evaluates the generated solution from a delivery and audit perspective. It combines technical review with runbook and certification outputs so the project can move into Handover with traceable evidence.

## What you can configure

There is no main user configuration layer in this phase. Governance runs on top of what Discovery, Triage, Drafting, and Refinement already produced.

## Main action

- **Run Governance**: executes the governance and certification workflow.

## Views you should use

| View | When to use it |
|---|---|
| **Overview / Report** | Best landing page for the phase. |
| **Execution Logs** | Use while governance is running or when a certification looks incomplete. |

## Main outputs

Governance should leave you with:

- certification score or decision
- governance observations
- runbook-oriented operational output
- a project state ready for Handover

## Done when

Governance is ready when:

- the certification run completed
- the report is available
- the team understands any remaining findings before delivery
