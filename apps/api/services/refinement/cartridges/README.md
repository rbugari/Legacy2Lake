# Cartridge Metadata Contract
**Version**: 3.6  
**Purpose**: Define expected input/output structures for all cartridges

---

## Input Structure: `table_metadata`

All cartridge methods (`generate_bronze`, `generate_silver`, `generate_gold`) expect a dictionary with the following structure:

### Required Fields

```python
{
    "source_path": str,           # Original file path (e.g., "customers.py", "orders.sql")
    "output_table_name": str,     # Target table name (e.g., "dim_customer", "fact_orders")
    "pk_columns": List[str],      # Primary key columns (e.g., ["customer_id"], ["order_id", "line_num"])
}
```

### Optional Fields

```python
{
    "table_type": str,            # "DIMENSION" or "FACT" (default: "DIMENSION")
    "original_code": str,         # Legacy source code to wrap/adapt
    "columns": List[Dict],        # Column metadata for advanced features
    "stage_name": str,            # For Snowflake COPY operations
}
```

### Example

```python
table_metadata = {
    "source_path": "legacy/dim_customer.py",
    "output_table_name": "dim_customer",
    "pk_columns": ["customer_id"],
    "table_type": "DIMENSION",
    "original_code": "df = spark.read.csv('customers.csv')",
    "columns": [
        {"name": "customer_id", "type": "integer", "nullable": False},
        {"name": "email", "type": "string", "nullable": False},
        {"name": "status", "type": "enum", "values": ["active", "inactive"]}
    ]
}
```

## Input Structure: `design_registry`

The registry contains project-level configuration passed to the cartridge constructor:

### Naming Conventions

```python
{
    "naming": {
        "bronze_schema": str,      # Default: "bronze_raw"
        "silver_schema": str,      # Default: "silver_curated"
        "gold_schema": str,        # Default: "gold_business"
        "bronze_prefix": str,      # Default: "" (no prefix)
        "silver_prefix": str,      # Default: "stg_"
        "gold_prefix": str,        # Default: "dim_" or "fact_"
    }
}
```

### Path Configuration

```python
{
    "paths": {
        "bronze_path": str,        # Default: "/mnt/datalake/bronze"
        "silver_path": str,        # Default: "/mnt/datalake/silver"
        "gold_path": str,          # Default: "/mnt/datalake/gold"
    }
}
```

### Technology-Specific Config

```python
{
    "tech_config": {
        "compliance_rules": {
            "base": str,                    # Base compliance rules from DB
            "source_overrides": {           # Source-specific overrides
                "oracle": str,              # Oracle-specific rules
                "mssql": str,               # SQL Server-specific rules
            }
        }
    }
}
```

### Example

```python
design_registry = {
    "naming": {
        "bronze_schema": "landing_zone",
        "silver_schema": "clean_layer",
        "gold_schema": "analytics",
        "silver_prefix": "stg_",
    },
    "paths": {
        "bronze_path": "abfss://data@storage/bronze",
        "silver_path": "abfss://data@storage/silver",
        "gold_path": "abfss://data@storage/gold",
    },
    "tech_config": {
        "compliance_rules": {
            "base": "Use Delta Lake format...",
            "source_overrides": {
                "oracle": "Convert NUMBER to DECIMAL..."
            }
        }
    }
}
```

## Output Structure

### `generate_bronze()`, `generate_silver()`, `generate_gold()`

**Returns**: `str` - Complete executable code for that layer

**Format**:
- PySpark: Python code (`.py`)
- Snowflake: Python (Snowpark) or SQL
- dbt: SQL with Jinja2 templating
- MS Fabric: Python or T-SQL

**Example Output (PySpark Bronze)**:
```python
# BRONZE LAYER INGESTION
# Generated by Legacy2Lake Architect Agent
# Source: customers.py

from config import Config
from utils import add_ingestion_metadata
# ... (complete runnable code)
```

---

### `generate_scaffolding()`

**Returns**: `Dict[str, str]` - Mapping of filename to file content

**Example**:
```python
{
    "config.py": "class Config:\n    CATALOG = 'main'\n    ...",
    "utils.py": "from pyspark.sql import DataFrame\n...",
    "dbt_project.yml": "name: 'migration_project'\n..."
}
```

---

### `generate_orchestration()`

**Input**: `List[Dict[str, Any]]` - List of tables with metadata

**Returns**: `str` - Orchestration code (Airflow DAG, Databricks Jobs, SQL Tasks)

**Example Input**:
```python
tables_metadata = [
    {"table_name": "customers", ...},
    {"table_name": "orders", ...}
]
```

**Example Output** (Airflow DAG):
```python
from airflow import DAG
from airflow.providers.databricks.operators import DatabricksSubmitRunOperator
# ... (complete DAG definition)
```

## Validation Rules

### Primary Keys (`pk_columns`)
- ✅ **Valid**: `["id"]`, `["customer_id", "order_date"]`, `"single_pk"`
- ❌ **Invalid**: `[]`, `None`, `123`, `{"key": "value"}`
- 🔄 **Auto-fixed to**: `["id"]` (safe default)

### Source Path (`source_path`)
- Must be a valid path string
- Extension used for file format detection (Snowflake)
- Basename used for table naming

### Table Type (`table_type`)
- Accepted values: `"DIMENSION"`, `"FACT"`
- Default: `"DIMENSION"`
- Case-insensitive

## Helper Methods (BaseCartridge)

### `_validate_and_normalize_pk(pk_columns)`

Ensures PK columns are always a valid list.

```python
# Examples:
_validate_and_normalize_pk(None)           # -> ["id"]
_validate_and_normalize_pk("customer_id")  # -> ["customer_id"]
_validate_and_normalize_pk([])             # -> ["id"]
_validate_and_normalize_pk(["a", "b"])     # -> ["a", "b"]
```

## Usage Examples

### Creating a Cartridge Instance

```python
from cartridges import PySparkCartridge

cartridge = PySparkCartridge(
    project_id="migration_001",
    design_registry={
        "naming": {
            "bronze_schema": "bronze_raw",
            "silver_schema": "silver_curated",
            "gold_schema": "gold_business"
        }
    }
)
```

### Generating Code

```python
# Generate scaffolding files
scaffold = cartridge.generate_scaffolding()
# Returns: {"config.py": "...", "utils.py": "..."}

# Generate Bronze layer
bronze_code = cartridge.generate_bronze({
    "source_path": "customers.csv",
    "pk_columns": ["customer_id"],
    "original_code": "df = spark.read.csv('data/customers.csv')"
})
# Returns: Complete Python code string

# Generate Silver layer
silver_code = cartridge.generate_silver({
    "source_path": "customers.csv",
    "output_table_name": "dim_customer",
    "pk_columns": ["customer_id"]
})
# Returns: Complete Python code with MERGE logic

# Generate Gold layer
gold_code = cartridge.generate_gold({
    "source_path": "customers.csv",
    "output_table_name": "dim_customer",
    "table_type": "DIMENSION"
})
# Returns: Complete Python code for business layer
```

## Technology-Specific Notes

### PySpark/Databricks
- Uses Delta Lake format by default
- Requires `Config.CATALOG` for Unity Catalog
- Supports schema evolution with `mergeSchema` option

### Snowflake
- Uses Snowpark for Python code
- Uses native SQL for `*_sql()` methods
- File format auto-detected from extension

### dbt
- Generates Jinja2-templated SQL
- Requires `dbt_project.yml` from scaffolding
- Incremental models use `is_incremental()` macro

### MS Fabric
- Dual output: PySpark Notebooks + T-SQL
- Includes TMDL for semantic models
- OneLake ABFSS paths available via `Config.get_abfss_path()`
