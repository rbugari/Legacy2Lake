### 7. SCD TYPE 2 PATTERN (Delta Lake MERGE — Silver Specialty)

**A. Add SCD Type 2 Columns**
```python
df_scd = df_quality \
    .withColumn("valid_from",        F.current_timestamp()) \
    .withColumn("valid_until",       F.lit(None).cast(TimestampType())) \
    .withColumn("is_current",        F.lit(True)) \
    .withColumn("record_version",    F.lit(1)) \
    .withColumn("silver_created_at", F.current_timestamp()) \
    .withColumn("silver_updated_at", F.current_timestamp())
```

**B. Create Silver Delta Table if Not Exists**
```python
if not DeltaTable.isDeltaTable(spark, silver_path):
    df_scd.limit(0).write \
        .format("delta") \
        .mode("append") \
        .option("mergeSchema", "true") \
        .save(silver_path)
    logger.info(f"[INIT] Created Silver Delta table: {silver_path}")
```

**C. SCD Type 2 MERGE (Delta `DeltaTable.merge` API)**
```python
merge_on = " AND ".join([f"target.{k} = source.{k}" for k in business_keys])

# Auto-detect change columns if not provided
change_cols = config.get('change_detection_cols', [])
if not change_cols:
    scd_sys = {"valid_from", "valid_until", "is_current", "record_version",
               "silver_created_at", "silver_updated_at", "is_complete_record"}
    change_cols = [c for c in df_scd.columns if c not in set(business_keys) | scd_sys]

change_cond = " OR ".join([f"target.{c} <> source.{c}" for c in change_cols])

silver_delta = DeltaTable.forPath(spark, silver_path)

# Step 1: Expire changed active records
silver_delta.alias("target").merge(
    df_scd.alias("source"),
    f"{merge_on} AND target.is_current = true"
).whenMatchedUpdate(
    condition=change_cond,
    set={
        "valid_until"       : "source.valid_from",
        "is_current"        : "false",
        "silver_updated_at" : "current_timestamp()"
    }
).execute()

# Step 2: Insert all incoming (new records + new versions of changed records)
df_scd.repartition(write_partitions).write \
    .format("delta") \
    .mode("append") \
    .option("mergeSchema", "true") \
    .save(silver_path)

logger.info(f"[LOAD] SCD Type 2 MERGE completed: {silver_path}")
```
