### 5. SCD TYPE 2 PATTERN (Historical Tracking - Silver Specialty)

**A. Add SCD Columns**

**B. MERGE with SCD Type 2 Logic**
```python
from delta.tables import DeltaTable

# Construct fully qualified silver table name
silver_table = f"{catalog}.{silver_schema}.{{{{target_table_name}}}}"

# Business key columns for matching (from config)
business_keys = config.get('business_keys', ['customer_id'])
merge_condition = " AND ".join([f"target.{key} = source.{key}" for key in business_keys])

# Create table if not exists (with SCD schema)
if not DeltaTable.isDeltaTable(spark, silver_table):
    empty_df = df_scd.limit(0)
    empty_df.write.format("delta") \
        .mode("append") \
        .option("mergeSchema", "true") \
        .saveAsTable(silver_table)
    logger.info(f"Created Silver Delta table with SCD Type 2 schema: {silver_table}")

# SCD Type 2 MERGE pattern
delta_table = DeltaTable.forName(spark, silver_table)

# Step 1: Close out old records (set valid_until, is_current=False)
delta_table.alias("target").merge(
    df_scd.alias("source"),
    f"{merge_condition} AND target.is_current = true"
).whenMatchedUpdate(
    condition="target.contact_name != source.contact_name OR target.city != source.city",  # Detect changes
    set={
        "valid_until": "source.valid_from",
        "is_current": "false",
        "silver_updated_at": "current_timestamp()"
    }
).execute()

# Step 2: Insert new versions (both new records and changed records)
df_scd.write.format("delta") \
    .mode("append") \
    .saveAsTable(silver_table)

logger.info(f"SCD Type 2 merge completed for {silver_table}")
```

### 10. SOURCE-SPECIFIC TRANSFORMATIONS

**For MS SQL Server Sources:**
- Handle legacy column naming: Convert `[Order ID]` → `order_id` (snake_case)
- Clean NVARCHAR artifacts: Trim whitespace with `F.trim()`
- Handle BIT columns: Cast to BooleanType

**For Oracle Sources:**
- Handle NUMBER(38,0): Cast to LongType (not IntegerType)
- Dates: Convert to DateType, handle timezone issues
- CHAR columns: Trim fixed-width padding

**For Legacy File Sources:**
- Parse filename metadata: Extract load date from `_source_file` column
- Handle encoding issues: Use `F.decode()` for binary columns
- CSV quirks: Handle embedded commas, quoted fields

### 11. SILVER-SPECIFIC BEST PRACTICES
- **Idempotency**: Silver layer should be replayable - same input = same output
- **No Business Logic**: Silver is cleansed/standardized data, NOT aggregated/calculated
- **Preserve Grain**: Do not aggregate - maintain same granularity as Bronze
- **Schema Evolution**: Use `.option("mergeSchema", "true")` for additive schema changes
- **Partitioning**: Consider partitioning by `valid_from` date for large SCD tables
