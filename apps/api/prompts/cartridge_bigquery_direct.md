### 2. DIRECT LAYER PHILOSOPHY

**Core Principle: Faithful 1:1 Logical Equivalence in BigQuery SQL**

This cartridge produces a `CREATE OR REPLACE PROCEDURE` that is a **faithful structural mirror** of the original logic (stored proc, SSIS, T-SQL job, Oracle PL/SQL) — rewritten in BigQuery Standard SQL.

**What Direct MUST preserve:**
- All filtering predicates → `WHERE` clauses
- Column derivations → `CASE WHEN / IF / IFNULL` in CTEs or SELECT
- Reference joins (Lookup) → `LEFT JOIN` / `INNER JOIN`
- Row routing/branching → separate `WHERE` filters per target INSERT
- Aggregations → `GROUP BY / HAVING`
- Row calculations → inline expressions in SELECT

**What Direct MUST NOT add:**
- No Bronze audit columns (`_ingestion_timestamp`, `_record_hash`)
- No Silver SCD columns (`VALID_FROM`, `IS_CURRENT`)
- No Gold surrogate keys (MD5 hash SK)
- No medallion enrichment of any kind

**⚠️ CRITICAL: Pure BigQuery SQL Scripting — no Spark, no Python, no `session` object.**

### 3. ZERO-HARDCODE POLICY
**✅ REQUIRED: All from procedure IN parameters**
```sql
CREATE OR REPLACE PROCEDURE {{dataset}}.SP_DIRECT_{{ASSET_NAME}}(
    IN p_project        STRING,     -- GCP project ID
    IN p_dataset        STRING,     -- Target dataset
    IN p_source_table   STRING,     -- Source table name
    IN p_target_table   STRING,     -- Target table name
    IN p_load_mode      STRING,     -- 'OVERWRITE' | 'APPEND' | 'MERGE'
    IN p_business_keys  STRING,     -- For MERGE: 'BK1,BK2'
    IN p_batch_date     DATE        -- Watermark / control date
)
```

### 4. PROCEDURE STRUCTURE (3-Stage with Exception Logging)

```sql
CREATE OR REPLACE PROCEDURE {{dataset}}.SP_DIRECT_{{ASSET_NAME}}(
    IN p_project      STRING,
    IN p_dataset      STRING,
    IN p_source_table STRING,
    IN p_target_table STRING,
    IN p_load_mode    STRING,
    IN p_business_keys STRING,
    IN p_batch_date   DATE
)
BEGIN
    DECLARE v_source_full STRING DEFAULT CONCAT('`', p_project, '.', p_dataset, '.', p_source_table, '`');
    DECLARE v_target_full STRING DEFAULT CONCAT('`', p_project, '.', p_dataset, '.', p_target_table, '`');
    DECLARE v_rows_written INT64  DEFAULT 0;

    -- [TRANSFORM] CTE chain — Section 5
    -- [LOAD]      OVERWRITE / APPEND / MERGE — Section 6

    SET v_rows_written = @@row_count;

    INSERT INTO {{dataset}}.L2L_EXECUTION_LOG
        (ASSET_NAME, LAYER, BATCH_DATE, ROWS_LOADED, STATUS, EXECUTED_AT)
    VALUES
        ('{{asset_name}}', 'DIRECT', p_batch_date, v_rows_written, 'SUCCESS', CURRENT_TIMESTAMP());

EXCEPTION WHEN ERROR THEN
    INSERT INTO {{dataset}}.L2L_EXECUTION_LOG
        (ASSET_NAME, LAYER, BATCH_DATE, STATUS, ERROR_MESSAGE, EXECUTED_AT)
    VALUES
        ('{{asset_name}}', 'DIRECT', p_batch_date, 'ERROR', @@error.message, CURRENT_TIMESTAMP());
    RAISE;
END;
```

### 5. DIRECT TRANSFORMATION PATTERNS (CTE-Based)

All transformations live in a **CTE chain** feeding the final INSERT/MERGE/CTAS.

**A. Column Derivation (SSIS Derived Column / SQL Computed Column)**
```sql
WITH
base AS (
    SELECT *
    FROM `project.dataset.source_table`    -- injected via v_source_full + EXECUTE IMMEDIATE
    WHERE DATE(load_date) >= p_batch_date
),
derived AS (
    SELECT
        BUSINESS_KEY_1,
        BUSINESS_KEY_2,
        UPPER(TRIM(NAME))                               AS NAME,
        CONCAT(FIRST_NAME, ' ', LAST_NAME)              AS FULL_NAME,
        ROUND(AMOUNT * FX_RATE, 4)                      AS AMOUNT_USD,
        DATE_TRUNC(TRANSACTION_DATE, MONTH)             AS PERIOD_MONTH,
        EXTRACT(YEAR FROM TRANSACTION_DATE)             AS TRANSACTION_YEAR,
        IF(AMOUNT > 0, TRUE, FALSE)                     AS IS_POSITIVE_AMOUNT
    FROM base
)
```

**B. Conditional Logic (CASE WHEN / IF — replaces SSIS Conditional Split / T-SQL IIF)**
```sql
filtered AS (
    SELECT
        *,
        CASE
            WHEN CATEGORY_CODE = 'A' THEN 'Premium'
            WHEN CATEGORY_CODE = 'B' THEN 'Standard'
            WHEN CATEGORY_CODE = 'C' THEN 'Economy'
            ELSE 'Unknown'
        END                                 AS CATEGORY_LABEL,
        IF(STATUS = 'ACT', TRUE, FALSE)     AS IS_ACTIVE,
        -- BigQuery: COALESCE, IFNULL, NULLIF
        COALESCE(DISCOUNT, 0.0)             AS DISCOUNT_SAFE,
        IFNULL(DESCRIPTION, 'N/A')          AS DESCRIPTION_CLEAN
    FROM derived
)
```

**C. Reference Lookup (LEFT JOIN — replaces SSIS Lookup)**
```sql
with_lookup AS (
    SELECT
        f.*,
        r.LOOKUP_VALUE      AS RESOLVED_LABEL,
        r.CATEGORY_GROUP    AS RESOLVED_GROUP
    FROM filtered f
    LEFT JOIN `project.dataset.reference_table` r    -- table ref from params
        ON f.LOOKUP_KEY = r.LOOKUP_KEY
),
```

**D. Row Routing / Multicast (SSIS Multicast → multiple INSERT targets)**
```sql
-- BigQuery: use a TEMP TABLE + multiple INSERT statements with WHERE filters
CREATE TEMP TABLE DIRECT_OUTPUT AS
SELECT * FROM with_lookup;

-- Route 1: valid records → main target
INSERT INTO `project.dataset.main_target`
SELECT * EXCEPT (IS_QUARANTINED) FROM DIRECT_OUTPUT
WHERE IS_QUARANTINED = FALSE;

-- Route 2: quarantine → error table
INSERT INTO `project.dataset.main_target_ERRORS`
SELECT *, CURRENT_TIMESTAMP() AS QUARANTINE_TS
FROM DIRECT_OUTPUT
WHERE IS_QUARANTINED = TRUE;
```

**E. Aggregation (GROUP BY / HAVING)**
```sql
grouped AS (
    SELECT
        DIMENSION_KEY,
        DATE_TRUNC(TRANSACTION_DATE, MONTH)     AS PERIOD_MONTH,
        COUNT(*)                                AS TRANSACTION_COUNT,
        SUM(AMOUNT_USD)                         AS TOTAL_AMOUNT,
        AVG(AMOUNT_USD)                         AS AVG_AMOUNT
    FROM with_lookup
    GROUP BY 1, 2
    HAVING COUNT(*) > 0
)
```

### 6. LOAD PATTERNS

**OVERWRITE (full replacement — BigQuery CTAS, atomic):**
```sql
EXECUTE IMMEDIATE FORMAT("""
    CREATE OR REPLACE TABLE %s
    OPTIONS (description = 'L2L Direct: {{asset_name}}')
    AS
    WITH
    base     AS (SELECT * FROM %s WHERE DATE(load_date) >= DATE('%s')),
    derived  AS (SELECT ..., CASE ... END AS COL FROM base),
    filtered AS (SELECT *, IF(...) AS IS_ACTIVE FROM derived)
    SELECT * FROM filtered
""",
v_target_full,
v_source_full,
CAST(p_batch_date AS STRING)
);
SET v_rows_written = @@row_count;
```

**APPEND (incremental — INSERT INTO ... SELECT):**
```sql
EXECUTE IMMEDIATE FORMAT("""
    INSERT INTO %s
    WITH
    base    AS (SELECT * FROM %s WHERE DATE(load_date) >= DATE('%s')),
    derived AS (SELECT ... FROM base)
    SELECT * FROM derived
    WHERE NOT EXISTS (
        SELECT 1 FROM %s t
        WHERE t.BUSINESS_KEY_1 = derived.BUSINESS_KEY_1
    )
""",
v_target_full,
v_source_full,
CAST(p_batch_date AS STRING),
v_target_full
);
SET v_rows_written = @@row_count;
```

**MERGE (upsert — when source had explicit upsert/update logic):**
```sql
EXECUTE IMMEDIATE FORMAT("""
    MERGE %s T
    USING (
        WITH
        base    AS (SELECT * FROM %s),
        derived AS (SELECT *, CASE ... END AS COL FROM base)
        SELECT * FROM derived
    ) S
    ON T.BUSINESS_KEY_1 = S.BUSINESS_KEY_1
       AND T.BUSINESS_KEY_2 = S.BUSINESS_KEY_2
    WHEN MATCHED THEN UPDATE SET
        T.ATTRIBUTE_A = S.ATTRIBUTE_A,
        T.AMOUNT      = S.AMOUNT
    WHEN NOT MATCHED THEN INSERT ROW
""",
v_target_full,
v_source_full
);
SET v_rows_written = @@row_count;
```

### 7. BIGQUERY SQL FUNCTION EQUIVALENCE TABLE

| Legacy / T-SQL | BigQuery SQL Equivalent |
|---|---|
| `ISNULL(col, default)` | `IFNULL(col, default)` or `COALESCE(col, default)` |
| `GETDATE()` / `SYSDATE` | `CURRENT_TIMESTAMP()` / `CURRENT_DATE()` |
| `CONVERT(INT, col)` | `CAST(col AS INT64)` |
| `CHARINDEX(str, col)` | `STRPOS(col, str)` ← arguments reversed in BQ |
| `SUBSTRING(col, 1, 5)` | `SUBSTR(col, 1, 5)` |
| `LEN(col)` | `LENGTH(col)` |
| `DATEADD(day, n, col)` | `DATE_ADD(col, INTERVAL n DAY)` |
| `DATEDIFF(day, d1, d2)` | `DATE_DIFF(d2, d1, DAY)` ← note argument order |
| `CAST(col AS NVARCHAR)` | `CAST(col AS STRING)` |
| `IIF(cond, a, b)` | `IF(cond, a, b)` |
| `NEWID()` | `GENERATE_UUID()` |
| `TOP n` | `LIMIT n` |
| `NOLOCK hint` | Not needed — BigQuery MVCC, no row locks |
| `@@ROWCOUNT` | `@@row_count` (BigQuery) |
| `PRINT 'msg'` | No equivalent — use INSERT to log table or `SELECT FORMAT(...)` |
| `BEGIN TRAN / COMMIT` | No explicit transactions in BigQuery SP scripting (each statement auto-commits) |
| `TRY/CATCH` | `EXCEPTION WHEN ERROR THEN` |
| `EXEC sp_name(params)` | `CALL dataset.sp_name(params)` |
| `OBJECT_ID('table')` | `INFORMATION_SCHEMA.TABLES` query |
| Oracle `NVL(col, v)` | `IFNULL(col, v)` or `COALESCE(col, v)` |
| Oracle `DECODE(col, ...)` | `CASE WHEN ... END` |
| Oracle `TO_DATE(str, fmt)` | `PARSE_DATE('%Y%m%d', str)` — BQ format string differs |
| Oracle `ROWNUM` | `ROW_NUMBER() OVER (ORDER BY ...)` |
| T-SQL `STUFF(...)` | `CONCAT` / `REPLACE` combination |

### 8. SSIS FLOW → BIGQUERY SQL MAPPING

| SSIS Component | BigQuery SQL Equivalent |
|---|---|
| OLE DB Source | CTE `base AS (SELECT * FROM \`project.dataset.table\`)` |
| OLE DB Destination | `INSERT INTO` / `CREATE OR REPLACE TABLE ... AS` / `MERGE` |
| Derived Column | `col_expr AS COL_NAME` in SELECT |
| Conditional Split | TEMP TABLE + separate INSERT per WHERE condition |
| Lookup (Full Cache) | `LEFT JOIN \`lookup_table\` ON key = key` |
| Lookup (No Cache) | `LEFT JOIN \`lookup_table\` ON key = key` (BQ auto-optimizes) |
| Aggregate | `GROUP BY ... HAVING` |
| Sort | `ORDER BY` — only in final output when order matters |
| Merge Join | `JOIN` — BQ optimizer handles distribution |
| Union All | `UNION ALL` |
| Multicast | TEMP TABLE + multiple INSERT to different targets |
| Data Conversion | `CAST(col AS TYPE)` / `SAFE_CAST(col AS TYPE)` |
| Row Count | `@@row_count` after last DML |
| Execute SQL Task (pre) | Separate `EXECUTE IMMEDIATE` at top of procedure |
| Execute SQL Task (post) | Separate `EXECUTE IMMEDIATE` at end of procedure |

### 9. BIGQUERY-SPECIFIC DIRECT PATTERNS

**`SAFE_CAST` for resilient type conversion (no exception on failure):**
```sql
-- T-SQL TRY_CAST → BigQuery SAFE_CAST
SAFE_CAST(col AS INT64)     -- returns NULL instead of error if cast fails
SAFE_CAST(col AS NUMERIC)
SAFE_CAST(col AS DATE)
```

**`STRUCT` for nested data (BigQuery-specific):**
```sql
-- Only if source had nested/repeated structure (JSON, XML source)
STRUCT(
    FIRST_NAME AS first_name,
    LAST_NAME  AS last_name
) AS name_struct
```

**`ARRAY_AGG` for list aggregation:**
```sql
ARRAY_AGG(DISTINCT tag ORDER BY tag) AS tags_list
```

**`FORMAT()` for dynamic SQL in EXECUTE IMMEDIATE:**
```sql
-- BigQuery uses FORMAT() for string formatting in EXECUTE IMMEDIATE
-- Snowflake uses similar FORMAT(), T-SQL uses FORMATMESSAGE()
EXECUTE IMMEDIATE FORMAT("SELECT * FROM `%s.%s.%s`", p_project, p_dataset, p_table);
```

### 11. BIGQUERY NATIVE OPTIMIZATION HINTS

**@@query_label — Billing Attribution (MANDATORY):**
```sql
-- Add at the very TOP of procedure body, before any DML:
SET @@script.query_label = CONCAT('l2l-direct-', LOWER('{{asset_name}}'), '-', CAST(p_batch_date AS STRING));
-- Visible in INFORMATION_SCHEMA.JOBS_BY_PROJECT for per-asset cost reporting.
```

**Result Cache — Direct OVERWRITE Queries:**
```sql
-- BQ caches identical query results for 24h. Keep SELECT list free of volatile functions:
-- BAD  (breaks cache): SELECT CURRENT_TIMESTAMP() AS etl_ts, col1, col2 FROM source
-- GOOD (cacheable):    SELECT col1, col2 FROM source WHERE load_date >= DATE('{{batch_date}}')
-- Tip: pass volatile values as procedure parameters and use them in WHERE/HAVING only.
```

**EXPORT DATA — Extract-to-GCS Pattern (Direct → Downstream):**
```sql
-- If Direct layer output feeds a non-BQ system (ML pipeline, reporting server, API):
EXECUTE IMMEDIATE FORMAT("""
    EXPORT DATA OPTIONS (
        uri       = 'gs://{{export_bucket}}/{{asset_name}}/%s/*.parquet',
        format    = 'PARQUET',
        overwrite = true
    )
    AS
    SELECT * FROM %s
""",
    CAST(p_batch_date AS STRING),
    v_target_full
);
-- Output: multiple sharded Parquet files in GCS. Orchestrator picks up the path for downstream.
-- EXPORT DATA supports: PARQUET, CSV, AVRO, NEWLINE_DELIMITED_JSON.
```

**@@script.bytes_processed — Cost Tracking:**

## 🎯 OUTPUT REQUIREMENTS
1. `CREATE OR REPLACE PROCEDURE` with BigQuery SQL Scripting
2. CTE chain: `base → derived → filtered → grouped` (as needed per source logic)
3. Load mode: `OVERWRITE` (CTAS) | `APPEND` (INSERT) | `MERGE`
4. `FORMAT(...)` string in all `EXECUTE IMMEDIATE` for dynamic refs
5. `EXCEPTION WHEN ERROR THEN` + INSERT to `L2L_EXECUTION_LOG`
6. NO Bronze/Silver/Gold medallion columns — pure 1:1 translation
7. No Python, no Spark — pure BigQuery SQL
8. L2L header: `Target Platform: Google BigQuery`, `Medallion Layer: direct`
9. SSIS component mapping (Section 8) guides the translation
10. `SAFE_CAST` where resilient conversion is appropriate
11. `@@row_count` for metrics, logged to `L2L_EXECUTION_LOG`
