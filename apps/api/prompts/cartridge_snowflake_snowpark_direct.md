### 2. DIRECT LAYER PHILOSOPHY

**Core Principle: Faithful 1:1 Logical Equivalence**

The Direct cartridge produces a **faithful structural mirror** of the original source logic using Snowflake Snowpark APIs — without Medallion enrichment, SCD Type 2, or surrogate key patterns.

**When Direct is used:**
- Source is a stored procedure, SSIS package, or ETL job with embedded business logic
- The logic is self-contained and doesn't require Silver/Gold transformations
- A rapid migration path is needed before later architectural refinement
- The business workflow explicitly requires a non-medallion integration point

**What Direct MUST preserve:**
- Filtering predicates (WHERE conditions → `.filter()`)
- Column derivations (Computed columns → `.with_column()`)
- Lookup operations (reference joins → `.join()`)
- Branching logic (CASE/IIF → `F.when().otherwise()`)
- Aggregation logic (GROUP BY → `.group_by().agg()`)
- Row routing/fanout (SSIS Multicast → cache + multi-target write)

**What Direct MUST NOT add:**
- No Bronze audit columns (`_INGESTION_TIMESTAMP`, `_RECORD_HASH`)
- No Silver SCD columns (`VALID_FROM`, `VALID_UNTIL`, `IS_CURRENT`)
- No Gold surrogate keys (SHA2 hash SK)
- No quality flags
- No medallion-specific columns of any kind

**⚠️ CRITICAL: Function signature is `execute_task(session, config)` — Snowpark `Session`, NOT PySpark `SparkSession`.**

### 5. EXTRACTION PATTERNS

**Pattern A: Source Table Already in Snowflake**
```python
source_full = f"{database}.{schema}.{source_table}"
df = session.table(source_full)

if filter_expr:
    df = df.filter(filter_expr)
    logger.info(f"[EXTRACT] Filter applied: {filter_expr}")

if batch_date:
    watermark_col = config.get('watermark_col', 'LOAD_DATE')
    df = df.filter(F.col(watermark_col) >= F.lit(batch_date).cast("date"))

source_count = df.count()
logger.info(f"[EXTRACT] {source_count} rows from: {source_full}")
```

**Pattern B: Source SQL Query (complex legacy SELECT translated)**
```python
source_sql = config.get('source_sql')
if source_sql:
    df = session.sql(source_sql)
    source_count = df.count()
    logger.info(f"[EXTRACT] {source_count} rows from SQL query")
```

### 6. DIRECT TRANSFORMATION PATTERNS

**A. Column Derivation (SSIS Derived Column / SQL Computed Column)**
```python
df = df \
    .with_column("FULL_NAME",
        F.concat_ws(F.lit(" "), F.col("FIRST_NAME"), F.col("LAST_NAME"))) \
    .with_column("AMOUNT_USD", F.round(F.col("AMOUNT_LOCAL") * F.col("FX_RATE"), 2)) \
    .with_column("IS_ACTIVE",  F.col("STATUS").isin(["A", "ACTIVE"])) \
    .with_column("YEAR_MONTH", F.date_format(F.col("TRANS_DATE"), "yyyyMM"))
    # Use F.to_char(F.col("TRANS_DATE"), "YYYYMM") for Snowflake-native format
```

**B. Conditional Logic (CASE WHEN / SSIS Conditional Split)**
```python
# Snowpark F.when().otherwise() is the equivalent of CASE WHEN
df = df.with_column(
    "CATEGORY_LABEL",
    F.when(F.col("CATEGORY_CODE") == F.lit("A"), F.lit("Premium"))
     .when(F.col("CATEGORY_CODE") == F.lit("B"), F.lit("Standard"))
     .when(F.col("CATEGORY_CODE") == F.lit("C"), F.lit("Economy"))
     .otherwise(F.lit("Unknown"))
)
```

**C. Reference Lookup (SSIS Lookup / SQL JOIN)**
```python
# Static lookup table from config (not hardcoded)
lookup_table  = config.get('lookup_table')
lookup_schema = config.get('lookup_schema', schema)

if lookup_table:
    lookup_full = f"{database}.{lookup_schema}.{lookup_table}"
    source_col  = config.get('lookup_source_col')
    lookup_key  = config.get('lookup_key_col')
    lookup_val  = config.get('lookup_value_col')

    df_lookup = session.table(lookup_full) \
        .select(F.col(lookup_key).alias("_LOOKUP_KEY"), F.col(lookup_val).alias("_LOOKUP_VAL"))

    df = df.join(df_lookup, df[source_col] == df_lookup["_LOOKUP_KEY"], "left") \
           .with_column(lookup_val, F.col("_LOOKUP_VAL")) \
           .drop("_LOOKUP_KEY", "_LOOKUP_VAL")

    logger.info(f"[TRANSFORM] Reference lookup joined: {lookup_full}")
```

**D. Multicast / Row Routing (SSIS Multicast — write same data to multiple targets)**
```python
# SSIS Multicast: same DataFrame written to multiple destinations
multiple_targets = config.get('output_targets', [])

if multiple_targets:
    df_cached = df  # Snowflake Snowpark DataFrames are lazy but re-runnable
                    # For efficiency, write once to a staging table, then SELECT INTO each target
    staging_full = f"{database}.{schema}.STAGING_{target_table}_TEMP"
    df_cached.write.mode("overwrite").save_as_table(staging_full)
    logger.info(f"[MULTICAST] Staged to: {staging_full}")

    for target_cfg in multiple_targets:
        t_full = f"{database}.{target_cfg.get('schema', schema)}.{target_cfg['table']}"
        t_filter = target_cfg.get('filter')
        df_target = session.table(staging_full)
        if t_filter:
            df_target = df_target.filter(t_filter)
        df_target.write.mode(target_cfg.get('mode', 'overwrite')).save_as_table(t_full)
        logger.info(f"[MULTICAST] Written to: {t_full}")

    # Clean up temp staging
    session.sql(f"DROP TABLE IF EXISTS {staging_full}").collect()
```

### 7. TYPE CASTING HELPER
```python
def _resolve_snowpark_type(dtype_str: str):
    """
    Map triage metadata type string → Snowpark DataType.
    Used for explicit casting only — Direct layer does NOT add audit columns.
    """
    mapping = {
        'STRING'    : StringType(),
        'VARCHAR'   : StringType(),
        'NVARCHAR'  : StringType(),
        'INT'       : IntegerType(),
        'INTEGER'   : IntegerType(),
        'BIGINT'    : LongType(),
        'DECIMAL'   : DecimalType(18, 4),
        'NUMERIC'   : DecimalType(18, 4),
        'FLOAT'     : FloatType(),
        'DOUBLE'    : DoubleType(),
        'DATE'      : DateType(),
        'DATETIME'  : TimestampType(),
        'TIMESTAMP' : TimestampType(),
        'BOOLEAN'   : BooleanType(),
        'BIT'       : BooleanType(),
    }
    return mapping.get(dtype_str.upper(), StringType())
```

### 8. LOAD PATTERNS (3 Modes)

**Mode A: Overwrite (default for Direct — full logical refresh)**
```python
target_full = f"{database}.{schema}.{target_table}"

df_final.write.mode("overwrite").save_as_table(target_full)
target_count = session.table(target_full).count()
logger.info(f"[LOAD] OVERWRITE → {target_full}: {target_count} rows")
```

**Mode B: Append (incremental batch)**
```python
df_final.write.mode("append").save_as_table(target_full)
target_count = session.table(target_full).count()
logger.info(f"[LOAD] APPEND → {target_full}: {target_count} total rows")
```

**Mode C: MERGE (upsert — when source had UPSERT/MERGE logic)**
```python
from snowflake.snowpark.functions import when_matched, when_not_matched

df_final.create_or_replace_temp_view("DIRECT_INCOMING")

merge_on = " AND ".join([f"t.{k} = s.{k}" for k in business_keys])
upd_set  = ", ".join([
    f"t.{c.name} = s.{c.name}"
    for c in df_final.schema.fields
    if c.name not in business_keys
])
ins_cols = ", ".join([c.name for c in df_final.schema.fields])
ins_vals = ", ".join([f"s.{c.name}" for c in df_final.schema.fields])

session.sql(f"""
    MERGE INTO {target_full} t
    USING DIRECT_INCOMING s
    ON {merge_on}
    WHEN MATCHED THEN UPDATE SET {upd_set}
    WHEN NOT MATCHED THEN INSERT ({ins_cols}) VALUES ({ins_vals})
""").collect()

target_count = session.table(target_full).count()
logger.info(f"[LOAD] MERGE → {target_full}: {target_count} rows")
```

### 10. SSIS COMPONENT MAPPING (Legacy Source Reference)

| SSIS Component | Snowpark Equivalent |
|---|---|
| Derived Column | `df.with_column("COL", F.expr(...))` |
| Conditional Split | `df.filter(cond)` → multiple DataFrames |
| Lookup (Full-Cache) | `.join(ref_df, ..., "left")` |
| Lookup (No-Cache) | `session.sql("SELECT ... FROM source JOIN ref ...")` |
| Multicast | Write to temp table → SELECT INTO each target |
| Sort | `.sort(F.col("COL").asc())` |
| Aggregate | `.group_by().agg(F.sum(), F.count(), ...)` |
| Merge Join (SORT-SORT) | `.join(df2, ...)` — Snowflake optimizes internally |
| Union All | `df1.union_all(df2)` |
| Data Conversion | `F.col("COL").cast(TargetType())` |
| Row Count (audit) | `df.count()` → log, return in result dict |
| OLE DB Source (SQL Server) | `session.table("SCHEMA.TABLE")` (post-load) |
| OLE DB Destination | `df.write.mode("...").save_as_table("SCHEMA.TABLE")` |
| Slowly Changing Dimension | **NOT in Direct** — use Silver cartridge for SCD |
| Execute SQL Task (pre/post) | `session.sql("...").collect()` before/after transform |

### 11. CODING STANDARDS
- UPPERCASE Snowflake identifiers
- `session.table("DB.SCHEMA.TABLE")` for full-path reads
- `F.when().otherwise()` for conditional logic (never nested Python `if/else` on DataFrame)
- `_resolve_snowpark_type()` for all explicit type conversion
- Cast all values from config to their correct types before use in queries
- 3-stage try/except structure: EXTRACT / TRANSFORM / LOAD (Section 9)
- Return dict includes `status`, `rows_source`, `rows_in_target`, `target_table`
- Section comments: `# [EXTRACT]`, `# [TRANSFORM]`, `# [LOAD]`, `# [RETURN]`

### 12. SOURCE-SPECIFIC NOTES

**From MS SQL Server SSIS packages:**
- SSIS variable bindings → `config['param_name']`
- OLEDB connection strings → Snowflake `session` object managed by orchestrator
- BIT columns → `BooleanType()` cast
- NVARCHAR(MAX) → `StringType()` (Snowflake VARCHAR up to 16MB)
- DATETIME2 → `TimestampType()`
- MONEY / SMALLMONEY → `DecimalType(19, 4)`

**From Oracle PL/SQL:**
- `NVL(col, default)` → `F.coalesce(F.col("col"), F.lit(default))`
- `DECODE(col, v1, r1, v2, r2, default)` → `.when().when().otherwise()`
- `ROWNUM` → `F.row_number().over(Window.order_by(...))`
- `SYSDATE` → `F.current_timestamp()`
- `TO_DATE('...', 'YYYYMMDD')` → `F.to_date(F.lit('...'), "YYYYMMDD")`

**From SQL Server T-SQL:**
- `ISNULL(col, default)` → `F.coalesce(F.col("col"), F.lit(default))`
- `GETDATE()` → `F.current_timestamp()`
- `CONVERT(INT, col)` → `F.col("col").cast(IntegerType())`
- `CHARINDEX(str, col)` → `F.charindex(F.lit(str), F.col("col"))`
- `SUBSTRING(col, 1, 5)` → `F.substring(F.col("col"), 1, 5)`
- `TRY_CAST(...)` → `F.try_cast(F.col("col"), TargetType())`
