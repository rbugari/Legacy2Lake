### 2. CLOUDERA / ICEBERG PLATFORM NOTES
- **Table Format**: Apache Iceberg (`USING iceberg`). Never use `format("delta")` — Delta Lake is Databricks-only.
- **Catalog**: Iceberg Hive Catalog (`spark_catalog`) backed by Cloudera Data Platform Metastore.
- **Storage**: Paths (HDFS or Ozone) are injected via `config`. Never construct paths manually.
- **Authentication**: Kerberos session is pre-authenticated by the orchestrator. Do not call `kinit` inside `execute_task`.
- **No `dbutils`**: `dbutils` is Databricks-only. Use `logging`, `os`, or standard Python for utilities.
- **MERGE**: Use `spark.sql("MERGE INTO ...")` syntax — Iceberg supports SQL MERGE natively in Spark 3.x.

**A. Add SCD Type 2 Columns**

**B. Create Silver Iceberg Table if Not Exists**
```python
silver_table = f"{catalog}.{silver_schema}.{config['target_table_name']}"

# Create via Spark SQL with Iceberg properties
spark.sql(f"""
    CREATE TABLE IF NOT EXISTS {silver_table}
    USING iceberg
    TBLPROPERTIES (
        'write.upsert.enabled'              = 'true',
        'write.merge.mode'                  = 'merge-on-read',
        'history.expire.max-snapshot-age-ms'= '604800000'
    )
    AS SELECT * FROM (SELECT * FROM {bronze_table} LIMIT 0)
""")
logger.info(f"[INIT] Silver Iceberg table ready: {silver_table}")
```

**C. SCD Type 2 MERGE via Spark SQL (Iceberg)**
```python
# Build dynamic merge condition from business keys
merge_on = " AND ".join([f"t.{k} = s.{k}" for k in business_keys])

# Build change detection from config or auto-detect all non-key/non-SCD columns
change_cols = config.get('change_detection_cols', [])
if not change_cols:
    scd_system_cols = {"valid_from", "valid_until", "is_current", "record_version",
                       "silver_created_at", "silver_updated_at", "is_complete_record"}
    change_cols = [
        c for c in df_scd.columns
        if c not in set(business_keys) | scd_system_cols
    ]
change_expr = " OR ".join([f"t.{c} <> s.{c}" for c in change_cols])

# Register incoming as temp view
df_scd.createOrReplaceTempView("_silver_incoming")

# Step 1: Expire changed active records
spark.sql(f"""
    MERGE INTO {silver_table} t
    USING _silver_incoming s
    ON {merge_on} AND t.is_current = true
    WHEN MATCHED AND ({change_expr}) THEN UPDATE SET
        t.valid_until        = s.valid_from,
        t.is_current         = false,
        t.silver_updated_at  = current_timestamp()
""")

# Step 2: Insert ALL incoming rows (new records + new versions of changed records)
spark.sql(f"""
    INSERT INTO {silver_table}
    SELECT * FROM _silver_incoming
""")

logger.info(f"[LOAD] SCD Type 2 Iceberg MERGE completed: {silver_table}")
```

    """
    Silver layer transformation for {{asset_name}} on Cloudera CDP + Iceberg.

    Responsibilities:
    - Read from Bronze Iceberg table
    - Deduplicate and cleanse (explicit type casting, standardization)
    - Data quality flags (non-blocking marks, not drops)
    - SCD Type 2 via Iceberg MERGE INTO (Spark SQL)
    - Write to Silver Iceberg table

    Required config keys:
      catalog_name       : Iceberg catalog (e.g. 'spark_catalog')
      bronze_schema      : Source schema   (e.g. 'bronze_raw')
      silver_schema      : Target schema   (e.g. 'silver_curated')
      source_table_name  : Bronze table name
      target_table_name  : Silver table name
      business_keys      : list[str] — columns for MERGE join condition
      change_detection_cols : list[str] — columns to detect attribute changes (optional)
      scd_enabled        : bool — enable SCD Type 2 (default True)
      quality_threshold  : float — quality alert threshold (default 0.95)
      write_partitions   : int — repartition count before write (default 8)
    """
    import logging
    from pyspark.sql import functions as F
    from pyspark.sql.types import (
        IntegerType, LongType, StringType, DecimalType,
        DateType, TimestampType, BooleanType
    )
    from pyspark.sql.window import Window
    from functools import reduce

    logger = logging.getLogger(__name__)
    logger.info(f"[START] Silver: {{{{asset_name}}}}")

    try:
        catalog       = config.get('catalog_name', 'spark_catalog')
        bronze_schema = config.get('bronze_schema', 'bronze_raw')
        silver_schema = config.get('silver_schema', 'silver_curated')
        business_keys = config.get('business_keys', ['id'])
        scd_enabled   = config.get('scd_enabled', True)

        # [EXTRACT FROM BRONZE]
        bronze_table = f"{catalog}.{bronze_schema}.{config['source_table_name']}"
        df_bronze = spark.table(bronze_table)
        bronze_count = df_bronze.count()
        if bronze_count == 0:
            return {"status": "SKIPPED", "reason": "empty_bronze"}

        # [TRANSFORM — DEDUP, CAST, QUALITY, SCD COLS]
        # ... deduplication (Section 5B) ...
        # ... type casting (Section 5C) ...
        # ... quality flags (Section 5D) ...
        # ... add SCD columns (Section 6A) ...

        # Repartition for balanced Iceberg file sizes
        df_scd = df_scd.repartition(config.get('write_partitions', 8))

        # [LOAD — ICEBERG MERGE]
        silver_table = f"{catalog}.{silver_schema}.{config['target_table_name']}"
        # ... Create table if not exists (Section 6B) ...
        # ... SCD Type 2 MERGE (Section 6C) or simple UPSERT (Section 7) ...

        active_count = spark.sql(
            f"SELECT COUNT(*) FROM {silver_table} WHERE is_current = true"
        ).collect()[0][0]
        logger.info(f"[DONE] {active_count} active records in {silver_table}")

        return {
            "status"            : "SUCCESS",
            "bronze_rows"       : bronze_count,
            "silver_rows_active": active_count
        }

    except Exception as e:
        logger.error(f"[ERROR] Silver transformation failed: {str(e)}")
        raise

# NO if __name__ == "__main__": block — orchestrator calls execute_task() directly
