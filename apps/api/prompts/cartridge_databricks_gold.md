**Dimension MERGE Pattern (SCD Type 2)**
```python
gold_table = f"{catalog}.{gold_schema}.dim_{{{{entity_name}}}}"

# Create dimension table if not exists
if not DeltaTable.isDeltaTable(spark, gold_table):
    empty_df = df_gold_dimension.limit(0)
    empty_df.write.format("delta") \
        .mode("append") \
        .option("mergeSchema", "true") \
        .saveAsTable(gold_table)
    logger.info(f"Created Gold Dimension table: {gold_table}")

# SCD Type 2 MERGE for dimensions
delta_table = DeltaTable.forName(spark, gold_table)

# Business key match condition
business_keys = config.get('business_keys', ['customer_id'])
merge_condition = " AND ".join([f"target.{key} = source.{key}" for key in business_keys])

# Detect changes (compare all dimension attributes)
change_detection_cols = config.get('change_detection_cols', ['customer_name', 'city', 'country'])
change_condition = " OR ".join([f"target.{col} != source.{col}" for col in change_detection_cols])

# Step 1: Expire old records
delta_table.alias("target").merge(
    df_gold_dimension.alias("source"),
    f"{merge_condition} AND target.is_active = true"
).whenMatchedUpdate(
    condition=change_condition,
    set={
        "expiration_date": "current_date()",
        "is_active": "false",
        "dimension_updated_at": "current_timestamp()"
    }
).execute()

# Step 2: Insert new versions
df_gold_dimension.write.format("delta") \
    .mode("append") \
    .saveAsTable(gold_table)

logger.info(f"Dimension SCD Type 2 merge completed: {gold_table}")
```

### 5. STAR SCHEMA BEST PRACTICES

**Dimension Design**
- Use surrogate keys (integers) for joins, not business keys
- Keep dimensions denormalized (wide tables)
- Add effective/expiration dates for SCD Type 2
- Include descriptive attributes for filtering/grouping

**Fact Design**
- Foreign keys reference dimension surrogate keys
- Include ALL relevant date dimensions (order_date, ship_date, delivery_date)
- Pre-calculate common measures (gross, tax, net amounts)
- Add degenerate dimensions (invoice_number) directly in fact table

**Performance**
- Use `broadcast()` for dimension joins (dimensions are small)
- Partition fact tables by date column
- Z-ORDER fact tables on common filter columns (customer_sk, product_sk)
