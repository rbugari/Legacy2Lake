### 2. SNOWFLAKE / SNOWPARK PLATFORM NOTES

**⚠️ CRITICAL DIFFERENCE FROM OTHER CARTRIDGES: Function signature is `execute_task(session, config)` — NOT `execute_task(spark, config)`. The Snowpark `Session` object replaces the PySpark `SparkSession`.**

- **Runtime**: Snowflake Snowpark for Python (runs inside Snowflake, no external cluster needed).
- **Session**: `snowflake.snowpark.Session` — pre-created by orchestrator, injected as `session`.
- **Functions**: `from snowflake.snowpark import functions as F` — similar to PySpark but NOT identical.
- **Types**: `from snowflake.snowpark.types import *` — similar names to PySpark but different module.
- **Writing**: `df.write.mode("overwrite").save_as_table("SCHEMA.TABLE")` — NOT `.format("delta").save()`.
- **MERGE**: Use `target_table.merge(source, join_expr, [when_matched(), when_not_matched()])` API OR `session.sql("MERGE INTO ...")`.
- **No Delta Lake**: Snowflake uses native table format. No `DeltaTable`, no `.format("delta")`.
- **No `spark.conf.set()`**: Snowpark uses Session parameters, not Spark conf.
- **Storage**: Snowflake internal stages (`@stage_name`) or external stages (S3, ADLS, GCS). Paths always from `config`.
- **Credentials**: Managed by Snowflake's Key Pair auth, OAuth, or SSO — injected by orchestrator. Do NOT hardcode.

### 6. EXPLICIT TYPE CASTING (Required)
```python
def _resolve_snowpark_type(dtype_str: str):
    """Map triage metadata type string → Snowpark DataType."""
    mapping = {
        'STRING'   : StringType(),
        'INT'      : IntegerType(),
        'BIGINT'   : LongType(),
        'DECIMAL'  : DecimalType(18, 4),
        'FLOAT'    : FloatType(),
        'DOUBLE'   : DoubleType(),
        'DATE'     : DateType(),
        'TIMESTAMP': TimestampType(),
        'BOOLEAN'  : BooleanType(),
    }
    return mapping.get(dtype_str.upper(), StringType())

columns_meta = config.get('columns', [])

if columns_meta:
    df_typed = df.select([
        F.col(c['name']).cast(_resolve_snowpark_type(c['data_type'])).alias(c['name'])
        for c in columns_meta
    ])
else:
    logger.warning("[CAST] No column metadata — types inferred from source schema")
    df_typed = df
```

### 7. BRONZE LAYER AUDIT COLUMNS (Required)
```python
# Add mandatory L2L audit columns for Bronze traceability
# Note: Snowflake uses CURRENT_TIMESTAMP() and SHA2() natively in SQL
# In Snowpark Python, F.current_timestamp() and F.sha2() are available

df_bronze = df_typed \
    .withColumn("_INGESTION_TIMESTAMP", F.current_timestamp()) \
    .withColumn("_INGESTION_DATE",      F.current_date()) \
    .withColumn("_SOURCE_FILE",         F.lit(config.get('source_file', 'stage_load'))) \
    .withColumn(
        "_RECORD_HASH",
        F.sha2(F.concat_ws(F.lit("||"), *[F.col(c['name']) for c in (columns_meta or [])]), F.lit(256))
        if columns_meta else F.lit("NO_HASH")
    )
```

### 8. SNOWFLAKE MERGE PATTERN (MANDATORY — No overwrite for incremental)

**Using Snowpark `merge()` API:**
```python
bronze_full_table = f"{database}.{bronze_schema}.{table_name}"

# Create table if not exists (schema inference from DataFrame)
try:
    session.table(bronze_full_table).count()
    table_exists = True
except Exception:
    table_exists = False
    logger.info(f"[INIT] Creating Bronze table: {bronze_full_table}")

if not table_exists:
    df_bronze.write \
        .mode("overwrite") \
        .save_as_table(bronze_full_table)
    logger.info(f"[INIT] Bronze table created with {df_bronze.count()} rows")
else:
    # MERGE for idempotent loads (Agent F compliant)
    from snowflake.snowpark.functions import when_matched, when_not_matched

    target_table = session.table(bronze_full_table)

    # Build join expression from business keys
    join_expr = None
    for key in business_keys:
        cond = target_table[key] == df_bronze[key]
        join_expr = cond if join_expr is None else join_expr & cond

    merge_result = target_table.merge(
        df_bronze,
        join_expr,
        [
            when_matched().update_all(),
            when_not_matched().insert_all()
        ]
    )

    logger.info(
        f"[LOAD] MERGE completed: "
        f"inserted={merge_result.rows_inserted}, "
        f"updated={merge_result.rows_updated}"
    )
```

**Alternative: MERGE via SQL (more explicit control)**
```python
df_bronze.create_or_replace_temp_view("BRONZE_INCOMING")

merge_on  = " AND ".join([f"t.{k} = s.{k}" for k in business_keys])
upd_cols  = ", ".join([f"t.{c['name']} = s.{c['name']}" for c in columns_meta if c['name'] not in business_keys]) if columns_meta else "t.* = s.*"
ins_cols  = ", ".join([c['name'] for c in columns_meta]) if columns_meta else "*"
ins_vals  = ", ".join([f"s.{c['name']}" for c in columns_meta]) if columns_meta else "s.*"

session.sql(f"""
    MERGE INTO {bronze_full_table} t
    USING BRONZE_INCOMING s
    ON {merge_on}
    WHEN MATCHED THEN UPDATE SET {upd_cols}
    WHEN NOT MATCHED THEN INSERT ({ins_cols}) VALUES ({ins_vals})
""").collect()

target_count = session.table(bronze_full_table).count()
logger.info(f"[LOAD] Bronze table now has {target_count} rows")
```

### 11. SNOWFLAKE NAMING CONVENTIONS
- Snowflake is **case-insensitive by default** for unquoted identifiers — they are stored as UPPERCASE.
- Use UPPERCASE for table names, schema names, column names in `config` keys: `'TABLE_NAME'`, `'SCHEMA_NAME'`.
- Use double-quotes only when intentionally case-sensitive: `"MyTable"` → stored as `MyTable`.
- Recommended convention: UPPER_SNAKE_CASE for all Snowflake objects.

### 13. CODING STANDARDS
- Use UPPERCASE for Snowflake identifiers (table names, column names)
- Use `session.table()` for reading existing Snowflake tables
- Use `when_matched().update_all()` / `when_not_matched().insert_all()` for simple MERGE

- Always `return` a dict with `status`, `rows_source`, and `rows_in_bronze`
