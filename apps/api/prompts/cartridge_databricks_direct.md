```python
def _parse_data_type(dtype_str):
    """Convert metadata string to PySpark type"""
    dtype_map = {
        'STRING': StringType(),
        'INT': IntegerType(),
        'BIGINT': LongType(),
        'DOUBLE': DoubleType(),
        'DECIMAL': DecimalType(38, 10),
        'DATE': DateType(),
        'TIMESTAMP': TimestampType(),
        'BOOLEAN': BooleanType()
    }
    return dtype_map.get(dtype_str.upper(), StringType())
```

### 10. SOURCE-SPECIFIC TRANSLATIONS

**For MS SQL Server Sources (SSIS):**
- Convert `ISNULL(col, default)` → `F.coalesce(F.col("col"), F.lit(default))`
- Handle square brackets: `[Order Details]` → `Order_Details` or preserve with backticks
- Convert `TOP N` → `.limit(N)`
- Convert `DATEADD/DATEDIFF` → `F.date_add()`, `F.datediff()`
- Convert `CASE WHEN` → `F.when().otherwise()`
- Convert `CAST(col AS type)` → `F.col("col").cast(type)`

**For Oracle Sources:**
- Handle `NUMBER(38,0)` as LongType (not IntegerType)
- Convert `TO_DATE(str, fmt)` → `F.to_date(F.col("str"), fmt)`
- Convert `TO_CHAR(date, fmt)` → `F.date_format(F.col("date"), fmt)`
- Convert `NVL(col, default)` → `F.coalesce(F.col("col"), F.lit(default))`
- Convert `DECODE` → `F.when().when()...otherwise()`
- Handle `ROWNUM` → `F.row_number().over(Window.orderBy(...))`

**For Informatica Sources:**
- Convert Lookup (cached) → `broadcast(df_lookup).join(...)`
- Convert Router → multiple `filter()` operations
- Convert Aggregator → `groupBy().agg()`
- Convert Sorter → `orderBy()`
- Convert Expression → `withColumn()` chain

**For DataStage Sources:**
- Convert Transformer → `withColumn()` chain
- Convert Lookup → `join()` with appropriate type
- Convert Aggregator → `groupBy().agg()`
- Convert Sort → `orderBy()`
- Convert Remove Duplicates → `dropDuplicates()`
