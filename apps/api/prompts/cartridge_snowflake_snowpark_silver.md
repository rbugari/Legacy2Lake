### 2. SNOWFLAKE / SNOWPARK PLATFORM NOTES

**⚠️ CRITICAL: Function signature is `execute_task(session, config)` — Snowpark `Session`, NOT PySpark `SparkSession`.**

- **MERGE API**: `target_table.merge(source, join_expr, [when_matched(...), when_not_matched(...)])` OR `session.sql("MERGE INTO ...")`.
- **No Delta Lake**: No `DeltaTable`, no `.format("delta")`. Snowflake uses native table storage.
- **No `spark.conf.set()`**: Use `session.query_tag` or `ALTER SESSION SET ...` for Snowflake session params.
- **Streams & Tasks**: For CDC-based Silver ingestion, Snowflake Streams on Bronze tables can be used. Enable via `config['use_stream'] = True`.
- **Clustering Keys**: Snowflake equivalent of partitioning. Use `CLUSTER BY (col)` DDL on Gold-bound Silver tables.
- **Time Travel**: Snowflake automatically retains history. No explicit SCD infrastructure needed for time travel queries — but SCD Type 2 is still built for schema-level compatibility.

### 7. SCD TYPE 2 PATTERN (Snowflake MERGE — Silver Specialty)

**A. Add SCD Type 2 Columns**

**C. SCD Type 2 MERGE via Snowflake SQL (Most Expressive)**
```python
df_scd.create_or_replace_temp_view("SILVER_INCOMING")

merge_on = " AND ".join([f"t.{k} = s.{k}" for k in business_keys])

# Auto-detect change columns if not provided
if not change_cols:
    scd_sys = {"VALID_FROM", "VALID_UNTIL", "IS_CURRENT", "RECORD_VERSION",
               "SILVER_CREATED_AT", "SILVER_UPDATED_AT", "IS_COMPLETE_RECORD"}
    change_cols = [
        c.name for c in df_scd.schema.fields
        if c.name not in set(business_keys) | scd_sys
    ]

change_expr = " OR ".join([f"t.{c} <> s.{c}" for c in change_cols])

if table_exists:
    # Step 1: Expire changed active records
    session.sql(f"""
        MERGE INTO {silver_full} t
        USING SILVER_INCOMING s
        ON {merge_on} AND t.IS_CURRENT = true
        WHEN MATCHED AND ({change_expr}) THEN UPDATE SET
            t.VALID_UNTIL        = s.VALID_FROM,
            t.IS_CURRENT         = false,
            t.SILVER_UPDATED_AT  = current_timestamp()
    """).collect()

    # Step 2: Insert all incoming (new + changed versions)
    session.sql(f"""
        INSERT INTO {silver_full}
        SELECT * FROM SILVER_INCOMING
    """).collect()

    logger.info(f"[LOAD] SCD Type 2 MERGE completed: {silver_full}")
```
