```python
# ✅ COMPLIANCE-REQUIRED: Create table if not exists (NO overwrite mode)
if not DeltaTable.isDeltaTable(spark, table_name):
    # Create empty table with schema (CTAS pattern)
    empty_df = df_bronze.limit(0)  # Schema only, no data
    empty_df.write.format("delta") \
        .mode("append") \
        .option("mergeSchema", "true") \
        .saveAsTable(table_name)
    logger.info(f"Created Delta table: {table_name}")

# ✅ ALWAYS use MERGE INTO (even for initial load)
delta_table = DeltaTable.forName(spark, table_name)

delta_table.alias("target").merge(
    df_bronze.alias("source"),
    "target.custid = source.custid"  # Business key from config
).whenMatchedUpdateAll(
).whenNotMatchedInsertAll(
).execute()

logger.info(f"MERGE completed for {table_name}")
```

**RATIONALE**: Agent F compliance requires MERGE INTO for ALL operations. Initial loads use empty CTAS + MERGE to maintain idempotency.

### 10. SOURCE-SPECIFIC ADAPTATIONS

**For MS SQL Server Sources:**
- Convert `ISNULL()` → `F.coalesce()`
- Handle square brackets in column names: `[Order Details]` → `Order_Details`
- Convert `TOP N` → `.limit(N)`

- Handle `NUMBER(38,0)` as DecimalType/LongType, not IntegerType
- Convert `TO_DATE/TO_CHAR` → `F.date_format()`
- Convert `NVL` → `F.coalesce()`
- Handle `ROWNUM` with window functions: `F.row_number()`
