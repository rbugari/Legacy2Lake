### 2. MICROSOFT FABRIC PLATFORM NOTES
- **Table Format**: Delta Lake on OneLake. Use `.format("delta")` for all operations.
- **Storage**: OneLake paths use ABFSS: `abfss://{workspace}@onelake.dfs.fabric.microsoft.com/{lakehouse_id}/Tables/{table_name}` — always from config.
- **Simplified access inside Notebook**: `spark.read.table("tablename")` and `spark.table("tablename")` work when the notebook is attached to a Lakehouse.
- **Secrets**: Use `mssparkutils.credentials.getSecret("keyvault_url", "secret_name")` — NOT `dbutils.secrets.get(...)`.
- **dbutils**: NOT available in Fabric. Use `mssparkutils` (or its alias `notebookutils`).
- **Fabric Optimizations**: Enable `spark.microsoft.delta.optimizeWrite.enabled` for auto file coalescing.
- **No Unity Catalog**: Fabric uses workspaces and lakehouses, not Databricks Unity Catalog syntax.

### 6. EXPLICIT TYPE CASTING (Required)
```python
from pyspark.sql.types import (
    StructType, StructField, StringType, IntegerType, LongType,
    DecimalType, DateType, TimestampType, BooleanType
)
import pyspark.sql.functions as F

columns_meta = config.get('columns', [])

def _resolve_type(dtype_str: str):
    """Map triage metadata string → PySpark DataType."""
    mapping = {
        'STRING'   : StringType(),
        'INT'      : IntegerType(),
        'BIGINT'   : LongType(),
        'DECIMAL'  : DecimalType(18, 4),
        'DATE'     : DateType(),
        'TIMESTAMP': TimestampType(),
        'BOOLEAN'  : BooleanType(),
    }
    return mapping.get(dtype_str.upper(), StringType())

if columns_meta:
    df_typed = df.select([
        F.col(c['name']).cast(_resolve_type(c['data_type'])).alias(c['name'])
        for c in columns_meta
    ])
else:
    logger.warning("[CAST] No column metadata provided — types inferred from JDBC schema")
    df_typed = df
```

### 8. DELTA LAKE MERGE PATTERN (MANDATORY — No mode("overwrite"))
```python
from delta.tables import DeltaTable

bronze_table_path = f"{config['lakehouse_path']}/Tables/{config.get('bronze_schema','bronze_raw')}/{config['table_name']}"
business_keys = config.get('business_keys', ['id'])
merge_on = " AND ".join([f"target.{k} = source.{k}" for k in business_keys])

# Create Delta table if it doesn't exist yet (schema-only using CTAS with LIMIT 0)
if not DeltaTable.isDeltaTable(spark, bronze_table_path):
    df_bronze.limit(0).write \
        .format("delta") \
        .mode("append") \
        .option("mergeSchema", "true") \
        .save(bronze_table_path)
    logger.info(f"[INIT] Created Bronze Delta table: {bronze_table_path}")

# All inserts / updates via MERGE INTO (idempotent, Agent F compliant)
delta_table = DeltaTable.forPath(spark, bronze_table_path)

delta_table.alias("target").merge(
    df_bronze.alias("source"),
    merge_on
).whenMatchedUpdateAll(
).whenNotMatchedInsertAll(
).execute()

target_count = spark.read.format("delta").load(bronze_table_path).count()
logger.info(f"[LOAD] MERGE completed. Bronze table now has {target_count} rows.")
```

**RATIONALE**: Agent F requires MERGE INTO for ALL operations to guarantee idempotency. Even initial loads use empty CTAS + MERGE.
