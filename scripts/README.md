# Scripts - v4.0 Utilities

Utility scripts for Legacy2Lake v4.0 development and prompt management.

---

## 📦 Available Scripts

### 1. `sync_prompts.py`
**Purpose:** Bidirectional sync between filesystem (.md files) and database

```powershell
# Sync from filesystem TO database
python scripts/sync_prompts.py

# Sync FROM database to filesystem (backup)
python scripts/sync_prompts.py from-db

# Check sync status
python scripts/sync_prompts.py status
```

**Use Cases:**
- After editing prompts in `prompt_lab/`, sync to DB
- Backup prompts from DB to filesystem
- Check if filesystem and DB are in sync

---

### 2. `extract_prompts_v39.py`
**Purpose:** Extract hardcoded templates from v3.9 cartridges to markdown format

```powershell
# Extract all cartridges
python scripts/extract_prompts_v39.py

# Extract specific cartridge
python scripts/extract_prompts_v39.py pyspark
python scripts/extract_prompts_v39.py snowflake
```

**Use Cases:**
- Initial migration from v3.9 to v4.0
- Extract hardcoded generation logic
- Create structured markdown prompts

**Output:** `prompt_lab/cartridges/<tech>/<layer>_layer.md`

---

### 3. `validate_generated_code.py`
**Purpose:** Validate Python code generated by cartridges

```powershell
# Validate all files in directory
python scripts/validate_generated_code.py output/project_123

# Validate single file
python scripts/validate_generated_code.py output/project_123/bronze_customers.py
```

**Checks Performed:**
- ✅ Python syntax validity
- ✅ PySpark specific requirements (SparkSession, Delta, metadata columns)
- ✅ Error handling presence
- ✅ Logging statements
- ⚠️ Technology-specific best practices

**Use Cases:**
- Validate generated code before delivery
- Test cartridge output quality
- Catch common issues early

---

### 4. `git_helper.py`
**Purpose:** Convenient Git operations for prompt management

```powershell
# Commit prompt changes
python scripts/git_helper.py commit "Update PySpark bronze prompt"

# Show diff for a prompt
python scripts/git_helper.py diff cartridges/pyspark/bronze_layer.md

# Show commit history
python scripts/git_helper.py history cartridges/pyspark/bronze_layer.md 5

# Git status for prompts
python scripts/git_helper.py status

# Show file content at specific commit
python scripts/git_helper.py show cartridges/pyspark/bronze_layer.md HEAD~1

# Show who modified each line
python scripts/git_helper.py blame cartridges/pyspark/bronze_layer.md
```

**Use Cases:**
- Track prompt changes over time
- Review prompt modifications
- Audit who changed what

## 🚀 Quick Start Workflow

### Sprint 0: Initial Setup

```powershell
# 1. Extract prompts from v3.9
python scripts/extract_prompts_v39.py

# 2. Review extracted prompts
cd prompt_lab/cartridges
# (Edit and enhance prompts)

# 3. Sync to database (after DB tables created)
python scripts/sync_prompts.py

# 4. Commit prompts to Git
python scripts/git_helper.py commit "Initial v4.0 prompts extracted from v3.9"
```

---

### Daily Development Workflow

```powershell
# 1. Edit prompts in prompt_lab/
# (Use VSCode editor)

# 2. Validate if needed
python scripts/validate_generated_code.py output/test_project

# 3. Sync to database
python scripts/sync_prompts.py

# 4. Commit changes
python scripts/git_helper.py commit "Enhanced PySpark prompts"

# 5. Check sync status
python scripts/sync_prompts.py status
```

## 📋 Requirements

All scripts require:
- Python 3.11+
- Packages: `supabase-py`, `psycopg2` (already in requirements.txt)
- Git (for git_helper.py)
- Access to Supabase database (via connect_supabase_dev.py)

No additional dependencies needed!

---

## 🎯 Integration with v4.0

These scripts are designed to support the v4.0 architecture:

```
v4.0 Workflow:
1. Edit prompts → prompt_lab/*.md (filesystem)
2. Sync → sync_prompts.py → utm_system_prompts (database)
3. Generate code → Agent C reads prompts from DB
4. Validate → validate_generated_code.py
5. Version control → git_helper.py
```

## 🐛 Troubleshooting

### "Table utm_system_prompts not found"
**Expected during Sprint 0.** The table will be created in v4.0 Sprint 1.
Scripts will show a warning but continue working with filesystem.

### "Git not found"
Make sure Git is installed and in your PATH:
```powershell
git --version
```

### "Failed to connect to database"
Check your connection in `connect_supabase_dev.py`
