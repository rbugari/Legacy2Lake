## 3. UX Improvements

### 3.1 User Flow Optimization
**Task:** Identify and document friction points

**Areas to analyze:**
1. **Onboarding flow**
   - First-time user experience
   - Project creation wizard
   - Time to first value

2. **Discovery/Triage flow**
   - Asset upload experience
   - Triage interface usability
   - Configuration complexity

3. **Generation/Drafting flow**
   - Code generation process
   - Review/approval workflow
   - Download/export experience

4. **Settings/Admin flows**
   - User management
   - Tenant configuration
   - Project settings

**Deliverable:** User flow diagrams with pain points highlighted

### 3.2 Accessibility Enhancements (WCAG 2.1 AA)
**Task:** Audit and fix accessibility issues

**Checklist:**
- [ ] All interactive elements keyboard accessible
- [ ] Focus indicators visible
- [ ] Color contrast ratios meet AA standard (4.5:1 for text)
- [ ] Alt text for images
- [ ] Semantic HTML usage
- [ ] ARIA labels where needed
- [ ] Screen reader testing
- [ ] Form error messages readable by assistive tech

**Tools:**
- axe DevTools
- Lighthouse accessibility audit
- WAVE browser extension

### 3.3 Performance Optimizations
**Task:** Identify and fix performance bottlenecks

**Metrics to improve:**
- First Contentful Paint (FCP) < 1.8s
- Largest Contentful Paint (LCP) < 2.5s
- Time to Interactive (TTI) < 3.8s
- Cumulative Layout Shift (CLS) < 0.1

**Optimization strategies:**
- Code splitting
- Lazy loading components
- Image optimization
- Bundle size reduction
- Eliminate render-blocking resources

### 3.4 Mobile Responsiveness
**Task:** Ensure all screens work well on mobile

**Breakpoints to test:**
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px
- Large desktop: > 1440px

**Critical mobile experiences:**
- Navigation menu (hamburger?)
- Tables/data grids (should scroll or transform)
- Forms (touch-friendly inputs)
- Modals/dialogs (full-screen on mobile?)

### 4.2 New Components to Create
**Task:** List new components needed for v4.0 features

**For v4.0 features:**

#### Column Profile Component (NEW)
```tsx
// apps/web/src/components/triage/ColumnProfilePanel.tsx
// Shows field-level analysis from Deep Forensic Triage
<ColumnProfilePanel 
  column={columnData}
  onRecommendationApply={handleApply}
/>
```

**Requirements:**
- Display statistical profile (min, max, mean, percentiles)
- Show quality score prominently
- PII badge if detected
- List of quality issues
- Recommendations with action buttons
- Sample data preview

#### Quality Score Card (NEW)
```tsx
// apps/web/src/components/common/QualityScoreCard.tsx
<QualityScoreCard 
  score={85} 
  size="lg"
  showLabel={true}
/>
```

**Requirements:**
- Circular progress indicator
- Color-coded (red < 50, yellow 50-79, green >= 80)
- Multiple sizes (sm, md, lg)
- Optional label
- Optional trend indicator

#### Validation Errors Display (NEW)
```tsx
// apps/web/src/components/generation/ValidationErrors.tsx
<ValidationErrors 
  errors={validationErrors}
  onFix={handleAutoFix}
/>
```

**Requirements:**
- List syntax/semantic errors
- Show line numbers
- Click to jump to code location
- Auto-fix button (if available)
- Collapsible groups

#### PII Badge (NEW)
```tsx
// apps/web/src/components/common/PIIBadge.tsx
<PIIBadge type="EMAIL" severity="high" />
```

**Requirements:**
- Color-coded by severity
- Icon indicator
- Tooltip with explanation
- Multiple types (EMAIL, PHONE, SSN, CREDIT_CARD, etc.)
