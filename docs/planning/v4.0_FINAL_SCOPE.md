## 🗄️ Database Schema (Simplified)

```sql
-- Tabla principal de prompts (GLOBAL)
CREATE TABLE utm_prompts (
    prompt_id TEXT PRIMARY KEY,
    content TEXT NOT NULL,
    tech_stack TEXT,
    pattern_type TEXT,
    agent_id TEXT,
    is_active BOOLEAN DEFAULT true,
    created_by UUID,
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW(),
    metadata JSONB
);

-- Historial automático (trigger) - READ-ONLY para ADMIN
-- IMPORTANTE: Esta tabla es SOLO para análisis y seguridad
-- NO hay UI de rollback - solo ADMIN puede consultar historial
CREATE TABLE utm_prompts_history (
    history_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    prompt_id TEXT NOT NULL,
    content TEXT NOT NULL,
    tech_stack TEXT,
    pattern_type TEXT,
    agent_id TEXT,
    metadata JSONB,
    changed_by UUID,
    changed_at TIMESTAMPTZ DEFAULT NOW()
);

-- Trigger que guarda versión anterior automáticamente (safety net)
-- Los usuarios NO interactúan con esto - es automático
CREATE TRIGGER prompt_version_trigger
    BEFORE UPDATE ON utm_prompts
    FOR EACH ROW
    EXECUTE FUNCTION save_prompt_version();
```

**Key points:**
- ❌ NO hay columna `tenant_id` (prompts globales)
- ❌ NO hay columna `version` con números (trigger simple)
- ✅ Historial se guarda automáticamente al hacer UPDATE
- ✅ Historial es READ-ONLY para ADMIN (análisis y seguridad)
- ❌ NO hay UI para cambiar versiones o hacer rollback
- ❌ Usuarios NO interactúan con versiones - solo ADMIN puede consultar historial
