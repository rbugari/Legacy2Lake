# Stage 1 - Discovery

> Last Updated: 2026-03-21

Discovery is the intake stage.

Its job is to:

- ingest source artifacts
- inventory files
- identify what is likely core, support, or noise
- prepare the project for assessment and triage

Typical inputs:

- SQL
- SSIS `.dtsx`
- manifests
- DDL
- support/config files

Main outcomes:

- file inventory
- initial manifest
- asset set ready for Quick Assessment and Scout/Triage
