# Stage 2 - Triage

> Last Updated: 2026-03-21

Triage is where the platform tries to understand the modernization problem before code generation.

Its job is to:

- assess viability
- detect technology and gaps
- build the modernization mesh
- identify business entities, dependencies, and risk signals

Main outputs:

- quick assessment
- scout findings
- Agent A mesh
- prioritized view of what is migrable and what still needs context
