## 🎯 Overview

v4.0 "Zero-Hardcode Core" eliminates ALL hardcoded templates from the codebase and replaces them with **dynamic, database-driven prompts**. This enables:

- ✅ Change prompts without redeploying backend
- ✅ Automatic version history for all prompt changes
- ✅ Field-level forensic analysis (PII detection, quality scoring)
- ✅ Real-time code validation during generation

## 🗄️ Database Changes

### New Tables

#### `utm_prompts` - Dynamic Prompts
```sql
CREATE TABLE utm_prompts (
    prompt_id TEXT PRIMARY KEY,        -- e.g., 'agent_c_bronze_pyspark'
    content TEXT NOT NULL,             -- Prompt template with {{variables}}
    tech_stack TEXT,                   -- 'pyspark', 'snowflake', 'dbt', etc.
    pattern_type TEXT,                 -- 'bronze', 'silver', 'gold'
    agent_id TEXT,                     -- 'agent-c', 'agent-a', etc.
    is_active BOOLEAN DEFAULT true,
    metadata JSONB,
    created_at TIMESTAMPTZ,
    updated_at TIMESTAMPTZ
);
```

#### `utm_prompts_history` - Automatic Versioning
```sql
CREATE TABLE utm_prompts_history (
    history_id UUID PRIMARY KEY,
    prompt_id TEXT NOT NULL,
    content TEXT NOT NULL,            -- Snapshot of previous content
    changed_by UUID,
    changed_at TIMESTAMPTZ,
    previous_content_hash TEXT
);
```

#### `utm_column_profiles` - Field-Level Analysis
```sql
CREATE TABLE utm_column_profiles (
    profile_id UUID PRIMARY KEY,
    project_id UUID NOT NULL,
    object_name TEXT NOT NULL,
    column_name TEXT NOT NULL,
    inferred_type TEXT,               -- 'STRING', 'INTEGER', 'DECIMAL', etc.
    nullability_score FLOAT,          -- 0.0 to 1.0
    quality_score INTEGER,            -- 0 to 100
    semantic_tags TEXT[],             -- ['PII', 'EMAIL', 'PHONE']
    pii_detected BOOLEAN,
    statistical_profile JSONB,
    recommendations JSONB
);
```

#### `utm_generation_outcomes` - Learning Data
```sql
CREATE TABLE utm_generation_outcomes (
    outcome_id UUID PRIMARY KEY,
    project_id UUID NOT NULL,
    agent_id TEXT NOT NULL,
    generated_code TEXT,
    validation_passed BOOLEAN,
    quality_score INTEGER,
    tokens_used INTEGER,
    model_used TEXT,
    duration_ms INTEGER
);
```

## 🔧 Using Prompt Service

### Loading Prompts

```python
from apps.api.services.prompts.prompt_service import PromptService

service = PromptService()

# Get by ID
prompt = await service.get_prompt("agent_c_bronze_pyspark")

# Get by filters
prompt = await service.get_active_prompt(
    agent_id="agent-c",
    tech_stack="pyspark",
    pattern_type="bronze"
)

# List all prompts
prompts = await service.list_prompts(agent_id="agent-c")
```

### Creating/Updating Prompts (ADMIN only)

```python
# Create new prompt
prompt = await service.create_prompt(
    prompt_id="agent_c_incremental_pyspark",
    content="# Incremental load template\n{{code}}",
    tech_stack="pyspark",
    pattern_type="incremental",
    agent_id="agent-c",
    metadata={
        "description": "Incremental load with watermark",
        "version": "4.0.0"
    }
)

# Update existing prompt
prompt = await service.update_prompt(
    prompt_id="agent_c_bronze_pyspark",
    content="# Updated template\n{{new_code}}",
    updated_by="admin-user-id"
)
# Note: Update automatically saves version to utm_prompts_history
```

### Viewing History (ADMIN only)

```python
# Get version history
history = await service.get_prompt_history(
    prompt_id="agent_c_bronze_pyspark",
    limit=10
)

for record in history:
    print(f"Changed at: {record['changed_at']}")
    print(f"Changed by: {record['changed_by']}")
    print(f"Content preview: {record['content'][:100]}...")
```

## 🎨 Prompt Template Syntax

### Variables

```python
# Simple variable
"Table name: {{table_name}}"

# Nested access
"Source: {{schema.table_name}}"

# With filters
"Schema: {{schema | json}}"
"Name: {{table_name | upper}}"
```

### Supported Filters

- `json` - Convert to JSON string
- `upper` - Convert to uppercase
- `lower` - Convert to lowercase
- `trim` - Remove whitespace
- `lines` - Join list with newlines

### Example Prompt Template

```python
# BRONZE LAYER INGESTION
# Source: {{schema.source_name}}
# Target: {{target_table_full}}

from pyspark.sql import SparkSession

# Configuration
CATALOG = "{{params.catalog_name}}"
BRONZE_SCHEMA = "{{params.bronze_schema}}"
TARGET_TABLE = "{{target_table_name}}"

# Initialize Spark
spark = SparkSession.builder.appName("bronze_{{schema.table_name}}").getOrCreate()

# Select columns
source_columns = {{columns_formatted}}

df_bronze = df_source.select(*source_columns)

print(f"✅ Bronze ingestion complete: {CATALOG}.{BRONZE_SCHEMA}.{TARGET_TABLE}")
```

## 🐛 Troubleshooting

### Issue: Prompts not loading

**Solution:**
```python
# Clear cache
from apps.api.services.prompts.prompt_service import PromptService
service = PromptService()
service.clear_cache()

# Or via API
curl -X POST http://localhost:8000/api/v1/prompts/cache/clear
```

### Issue: Template variables not substituting

**Check your template syntax:**
```python
# ✅ Correct
"Table: {{table_name}}"

# ❌ Wrong
"Table: {table_name}"    # Missing double braces
"Table: ${table_name}"   # Wrong syntax
```

### Issue: PII detection not working

**Check column values:**
```python
# Ensure you're passing actual sample values
values = ["user@test.com", "admin@example.com"]  # ✅ Good
values = ["email"]  # ❌ Bad - generic name, not actual values
```
