Este directorio contiene los scripts de migración para v3.9 Multi-User.

## 📋 Scripts Order

**CRITICAL**: Ejecutar en este orden exacto.

```
010_v3.9_create_users_table.sql        ✅ Crear tabla utm_users
011_v3.9_create_invitations_table.sql  ✅ Crear tabla utm_user_invitations
012_v3.9_refactor_tenants.sql          ✅ Refactor utm_tenants
013_v3.9_update_projects.sql           ✅ Agregar created_by_user_id
014_v3.9_update_process_locks.sql      ✅ Agregar locked_by_user_email
015_v3.9_data_migration.sql            ⚠️  CRITICAL: Migrar datos existentes

```

## 🚀 Execution

### Local / Staging
```powershell
# Cd al directorio
cd c:\proyectos_dev\UTM\supabase_migrations

# Ejecutar cada script
psql $DB_URL -f 010_v3.9_create_users_table.sql
psql $DB_URL -f 011_v3.9_create_invitations_table.sql
psql $DB_URL -f 012_v3.9_refactor_tenants.sql
psql $DB_URL -f 013_v3.9_update_projects.sql
psql $DB_URL -f 014_v3.9_update_process_locks.sql
psql $DB_URL -f 015_v3.9_data_migration.sql
psql $DB_URL -f 016_v3.9_rls_policies.sql

# Verificar
psql $DB_URL -c "SELECT count(*) FROM utm_users;"
psql $DB_URL -c "SELECT count(*) FROM utm_tenants;"
```

### Production (Con precauciones)
```powershell
# 1. BACKUP PRIMERO
pg_dump $PROD_DB_URL > prod_backup_pre_v39_$(Get-Date -Format 'yyyyMMdd_HHmmss').sql

# 2. Ejecutar en transaction
psql $PROD_DB_URL << EOF
BEGIN;
\i 010_v3.9_create_users_table.sql
\i 011_v3.9_create_invitations_table.sql
\i 012_v3.9_refactor_tenants.sql
\i 013_v3.9_update_projects.sql
\i 014_v3.9_update_process_locks.sql

-- ROLLBACK;
EOF
```

## 🔄 Rollback

Si algo sale mal:

```powershell
psql $PROD_DB_URL -f ROLLBACK_v3.9.sql
```

## ✅ Verification Queries

Después de migration:

```sql
-- Verify table exists
SELECT table_name 
FROM information_schema.tables 
WHERE table_name IN ('utm_users', 'utm_user_invitations');

-- Verify data migrated
SELECT count(*) FROM utm_users;
SELECT count(*) FROM utm_tenants;

-- Check first users
SELECT u.user_id, u.email, u.role, t.org_name 
FROM utm_users u 
JOIN utm_tenants t ON u.tenant_id = t.tenant_id
LIMIT 10;

-- Verify no data loss
SELECT 
    (SELECT count(*) FROM utm_tenants_old) AS old_count,
    (SELECT count(*) FROM utm_tenants) AS new_count,
    (SELECT count(*) FROM utm_users) AS user_count;
```

## 📝 Notes

- Todos los scripts son **idempotent** (se pueden ejecutar múltiples veces)
- Script 015 tiene validaciones built-in
- Usa transacciones para rollback automático en error
- RLS policies aseguran tenant isolation
